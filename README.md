# Viva New Vegas 한국어 가이드

ModdingLinked의 [Viva New Vegas](https://vivanewvegas.moddinglinked.com/)를 바탕으로 한 **비공식 한국어 번역 프로젝트**입니다.

- 원본 프로젝트: ModdingLinked/Viva-New-Vegas
- 원본 가이드: https://vivanewvegas.moddinglinked.com/
- 한국어 패처: https://github.com/munument1/-KR-VivaNewVegas-Patcher
- 라이선스: 원본 MIT 라이선스 유지

## 현재 상태

한국어 번역 작업 중입니다. 제작자와의 협의 및 공개 준비가 끝나기 전까지 웹 페이지에는 `noindex, nofollow`가 적용되어 있습니다.

현재 적용된 작업:

- 전체 HTML 공통 한국어 메뉴
- 한국어 패치 전용 안내 페이지 / KR 변경사항 / 원본 가이드 링크
- VNV Korean Patcher v1.0.3 다운로드 및 업데이트 대응 안내
- 메인 페이지 번역
- 소개 페이지 번역
- 한국어판 전용 변경사항 페이지

원본 가이드의 설치 순서와 기술적 의미는 임의로 변경하지 않는 것을 원칙으로 합니다. 한국어 사용자에게 필요한 추가 설명은 원본 내용과 구분하여 표시합니다.

## 저작권 및 출처

원본 Viva New Vegas의 저작권 및 라이선스 고지는 그대로 유지합니다. 이 저장소의 한국어 번역은 공식 ModdingLinked 배포판이 아닙니다.
