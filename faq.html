일반

필요 사양과 지원되는 게임 버전은 무엇인가요?

소개 페이지를 확인하세요.

기존 세이브를 사용할 수 있나요?

짧게 답하면 안 됩니다.

기존 Fallout: New Vegas 세이브를 Viva New Vegas에서 그대로 사용하는 것은 권장되지 않습니다. 불러오기에 성공하더라도 변경 사항이 너무 많아 정상 작동을 보장할 수 없습니다. 이렇게 사용한 구성은 지원 대상이 아닙니다.

Linux를 지원하나요?

Linux 지원은 계획되어 있지만 당장은 아닙니다. 현재는 Discord 서버의 전용 채널에서 제한적으로 지원됩니다.

Fluorine과 Amethyst 같은 프로젝트 덕분에 Linux 환경도 상당히 개선되었습니다. 기본적인 Linux 사용법에 익숙하다면 별도의 자세한 안내 없이도 사용할 수 있는 수준을 목표로 하고 있습니다.

불법 복제판도 작동하나요?

불법 복제판은 어떤 형태로도 지원하지 않습니다. 불법 복제판 사용 사실이나 관련 대화가 확인되면 ModdingLinked Discord에서 차단될 수 있습니다.

New Vegas Multiplayer(NV:MP)를 사용할 수 있나요?

NVMP는 지원하지 않습니다. 관련 문의는 NVMP 커뮤니티에 해주세요.

세이브 파일은 어디에 저장되나요?

MO2로 게임을 실행하면 일반적인 Documents 폴더에 세이브가 보이지 않을 수 있습니다. 이 가이드와 Wabbajack은 프로필별 세이브 기능을 사용해 세이브를 해당 MO2 인스턴스의 프로필 폴더로 저장합니다. 오른쪽 패널의 Saves 탭에서 빠르게 확인할 수 있습니다.

바닐라 세이브나 다른 모드 구성에서 만든 세이브를 재사용하지 마세요. 정상적인 게임을 위해 새 캐릭터를 시작해야 합니다.

문제 해결

아래 방법으로 해결되지 않으면 ModdingLinked Discord에서 지원을 요청할 수 있습니다.

게임 실행 시 튕기거나 아무 반응이 없습니다

이 문제는 여러 원인으로 발생할 수 있습니다.

  • 여기의 절차대로 최신 VC++ 재배포 패키지가 설치되어 있는지 확인하세요.
  • DirectX 재배포 패키지가 정상적으로 설치되어 있는지 확인하세요.
    1. DirectX Redists Remover Script를 다운로드하고 압축을 풉니다.
    2. 스크립트를 관리자 권한으로 실행합니다.
    3. PC를 재부팅합니다.
    4. DirectX Redists Web Installer를 다운로드해 실행합니다.

      5. 설치 프로그램은 기본적으로 Bing Bar도 설치하려고 합니다.
      두 번째 화면에서 반드시 체크를 해제하세요.

    5. PC를 재부팅합니다.
  • Base Address Randomization이 활성화되어 있을 수 있습니다. 모드 환경에서는 비활성화해야 하므로 이 절차를 따르세요.
  • 4GB Patcher 또는 Epic Games Patcher를 실행하지 않았을 수 있습니다. 수동 설치는 가이드 절차를, Wabbajack은 이 절차를 따르세요.
  • xNVSE가 없거나 잘못 설치되었을 수 있습니다. 필수 유틸리티가 모두 설치되어 있는지 확인하세요. Wabbajack 사용자는 이 절차를 따르세요.
  • 게임 Data 폴더에 이전 모드 파일이 남아 있을 수 있습니다. 그래서 깨끗한 재설치가 필요합니다.
  • AMD GPU를 사용한다면 드라이버가 최신 버전인지 확인하거나 Performance Guide에 따라 DXVK를 사용하세요.
  • 타사 백신을 사용한다면 Mod Organizer 2 폴더를 예외에 추가하세요. 그래도 해결되지 않으면 타사 백신을 비활성화하고 Windows Defender만 사용하는 방법도 고려할 수 있습니다.
  • Overwolf를 종료하거나 제거합니다.
  • 완제품 PC나 노트북에 기본 설치된 관리 프로그램(예: HP OMEN의 OMEN Gaming Hub)은 충돌을 일으킬 수 있으므로 제거하거나 임시 종료하는 것이 좋습니다.
  • Performance Guide에 따라 FPS를 120 미만으로 제한하세요.
  • 그래픽 드라이버를 최신으로 업데이트하세요(Nvidia, AMD, Intel).

메인 메뉴가 분홍색으로 보입니다

Fallout.ini의 SMainMenuMovieIntro 값이 비어 있어야 하는데 0으로 설정되면 발생합니다. 이는 BethINI의 알려진 문제이며, 이 가이드의 Custom INI를 사용한다면 BethINI는 필요하지 않습니다.

메시가 사라지고 빨간 마름모가 보입니다

  1. Steam 또는 GOG Galaxy에서 게임 파일을 검증합니다.
  2. 게임 버전에 맞는 패처를 다시 실행합니다.
  3. Vanilla BSAs Patcher를 다시 실행합니다.

모드 목록이나 로드 순서를 어떻게 내보내나요?

MO2만 지원하므로 다른 모드 관리자에 대한 설명은 제공하지 않습니다.

  1. MO2 상단의 폴더 메뉴를 누릅니다.
  2. Open Profile Folder를 누릅니다.
  3. 모드 목록은 modlist.txt에 역순으로 기록되고, 로드 순서는 loadorder.txt에 저장됩니다. modlist.txt는 텍스트 편집기로 쉽게 순서를 뒤집을 수 있습니다.

GECK에서 모드가 보이지 않습니다

MO2에서는 GECK를 포함한 대부분의 도구를 MO2의 실행 목록에서 실행해야 합니다. 그래야 프로그램이 VFS와 함께 실행되어 설치한 모드를 모두 볼 수 있습니다.

MO2 인스턴스 생성 시 New Vegas가 목록에 없습니다

게임을 한 번 직접 실행한 뒤 MO2 설치 프로그램을 다시 시작하고 시도하세요.

INI를 초기화하려면 어떻게 하나요?

  1. MO2 상단의 버튼을 누르고 INI Editor를 선택합니다.
  2. Fallout.ini와 FalloutPrefs.ini의 내용을 모두 지우고 각각 저장합니다.
  3. MO2에서 게임 런처를 실행하면 새 INI가 생성됩니다.

이 가이드를 따랐다면 프로필별 INI를 사용하므로 MO2 안에서 이 작업을 해야 합니다.

게임 파일 검증을 해도 안전한가요?

게임 파일 검증을 하면 BSA 패치와 실행 파일 패치가 원상복구됩니다. 게임 버전에 맞는 패처를 다시 실행한 뒤 Vanilla BSAs Patcher도 다시 실행하세요.

쿼리 중 플러그인이 호환되지 않는다고 표시됩니다

게임용 모드가 GECK용이 아니라고 로그를 남기거나 그 반대인 경우입니다. 안전하게 무시해도 됩니다.

Application load error(Steam Error 65434 / 65432)

  • 5:0000065434: Steam이 실행 중인지 확인하세요. 해결되지 않으면 Steam에서 게임을 한 번 직접 실행해보세요. Steam이나 MO2 재시작이 필요할 수도 있습니다.
  • P:0000065432: PCR 버전에서 발생합니다. MO2 실행 파일 설정에서 Steamapp ID를 재정의하고 22490으로 설정하세요.

MO2에서 왼쪽 패널의 모드가 loose 파일을 덮어썼다고 표시합니다

MO2 왼쪽 패널의 모드 순서가 가이드와 정확히 같다면 이는 의도된 정상 상태입니다.

NVTF가 정상 설치되어 있는데 Utilities Checker에서 없다고 표시합니다

PC 재부팅으로 해결되지 않으면 다음을 시도하세요.

  1. DirectX Redists Remover Script를 다운로드하고 압축을 풉니다.
  2. 스크립트를 관리자 권한으로 실행합니다.
  3. PC를 재부팅합니다.
  4. DirectX Redists Web Installer를 다운로드해 실행합니다.

    5. 설치 프로그램은 기본적으로 Bing Bar도 설치하려고 합니다.
    두 번째 화면에서 반드시 체크를 해제하세요.

  5. PC를 다시 재부팅합니다.

NPC가 튀거나 게임 속도가 빨라집니다

Performance Guide에 따라 FPS를 120 미만으로 제한하세요.

지형 일부가 검게 보입니다

Improved Lighting Shaders가 원인일 수 있습니다. Vanilla Plus Terrain으로 교체하세요.

MO2가 실행되지 않고 매번 dump 파일만 생성됩니다

여기의 절차대로 최신 VC++ 재배포 패키지가 설치되어 있는지 확인하세요.

Alt+Tab 후 게임이 튕기거나 다시 열리지 않습니다

NVTF의 텍스처 RAM 사용 방지 설정 때문에 발생할 수 있으며, 이 설정은 Alt+Tab 기능을 깨뜨리는 단점이 있습니다.
정상적인 Alt+Tab을 사용하려면 DXVK 또는 창 모드를 사용해야 합니다.
자세한 설명과 해결 절차는 Performance Guide를 참고하세요.

모드가 MO2로 다운로드되지 않거나 Vortex로 받아집니다

  1. MO2 상단의 버튼을 눌러 설정을 엽니다.
  2. Nexus 탭에서 Connect to Nexus를 선택합니다.
  3. 브라우저가 열리면 연결을 승인합니다.
  4. 승인이 끝나면 브라우저 탭과 MO2 설정 창을 닫습니다.
  5. MO2가 재시작되도록 합니다.

Wabbajack 설치 중 오류가 발생합니다

  • Epic Games Store 버전을 사용 중인지 확인하세요. 이 Wabbajack 리스트는 해당 버전을 지원하지 않습니다.
  • 예약 구매 팩을 포함한 모든 DLC가 설치된 깨끗한 게임 설치 상태인지 확인하세요.
  • 게임 언어를 영어로 설정하세요. 다른 언어는 지원하지 않습니다.
  • 그래도 해결되지 않으면 Wabbajack 오른쪽 위 설정에서 Nexus 로그아웃 후 다시 로그인하고 설치를 다시 시작하세요.

"Vanilla UI Plus has detected an installation error" 오류

  1. MO2 왼쪽 패널에서 Vanilla UI Plus를 The Mod Configuration Menu 아래로 이동합니다.
  2. 가이드의 로드 순서를 적용했는지 확인하세요.

"Failed to initialize render" 오류

  1. MO2 상단의 버튼을 누르고 INI Editor를 선택합니다.
  2. FalloutPrefs.ini 탭을 선택합니다.
  3. Display 항목에서 다음 값을 변경합니다.
    iSize W = 화면 가로 해상도.
    iSize H = 화면 세로 해상도.

설정

FOV는 어떻게 바꾸나요?

  1. MO2 상단의 버튼을 누르고 INI Editor를 선택합니다.
  2. Custom INI 절차를 따랐다면 가이드 설정이 들어 있는 FalloutCustom.ini 탭을 선택합니다.
  3. 세 가지 FOV 값을 원하는 대로 수정하고 저장합니다.

LOD를 다시 생성해야 하나요?

새 LOD 생성은 필수는 아닙니다. 다만 수정된 근거리 셀과 원거리 셀의 외형을 맞춰 갑작스러운 차이를 줄이고 디테일도 크게 개선할 수 있어 일반적으로 권장됩니다.

전체 절차는 LOD 가이드에서 확인할 수 있습니다.

어떤 INI 변경이 필요한가요?

안정성과 성능에 필요한 INI 변경은 가이드의 Custom INI에 이미 모두 포함되어 있습니다.
추가로 조정하고 싶은 설정이 있다면 MO2의 INI Editor를 통해 FalloutCustom.ini에 추가하세요.

왜 DLC 플러그인을 xEdit로 클리닝하지 않나요?

Ultimate Edition ESM Fixes Remastered가 자동 xEdit 클리닝보다 훨씬 폭넓게 이미 처리합니다.

울트라와이드를 지원하나요?

지원합니다. 다만 추가 설정이 필요합니다.

  1. MO2 상단의 버튼을 누르고 INI Editor를 선택합니다.
  2. FalloutPrefs.ini 탭을 선택합니다.
  3. Display 항목에서 다음 값을 변경합니다.
    iSize W = 화면 가로 해상도.
    iSize H = 화면 세로 해상도.
  4. 게임을 실행하고 설정의 Tweaks 메뉴를 엽니다.
  5. Ultrawide를 검색한 뒤 지원 옵션을 활성화합니다.
