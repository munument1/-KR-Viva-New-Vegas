UI Improvements

Quality of life UI features, improvements, and a few bug fixes.

Installation instructions

  • Main Files - UI Improvements
    1. Once the mod has been installed, double-click it in the left pane of MO2.
    2. In the INI Files tab, open config\UII_Config.ini
    3. Set ExpandedAttributeInfo and ExpandedSkillInfo to 0, fixing stutter.
    4. Save your changes.
