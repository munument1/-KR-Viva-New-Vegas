MO2에 구분선 만들기

  2. 구분선 이름을 User Interface로 지정합니다.

The Mod Configuration Menu

여러 모드의 설정을 게임 안의 하나의 메뉴에서 관리할 수 있게 합니다.

설치 방법

  • Main Files - The Mod Configuration Menu

    • 설치 창의 크기가 비정상적으로 표시되면 Enter 키를 눌러 설치를 진행하세요.

MCM Extender

설치 방법

  • Main Files - MCM Extender

Vanilla UI Plus

원작의 분위기를 해치지 않으면서 사용자 인터페이스를 개선합니다.

설치 방법

  • 모드를 다운로드한 뒤 MO2 상단의 버튼을 눌러 방금 받은 파일을 선택해 수동 설치합니다.
    • FOMOD 설치 화면이 나타나면 원하는 취향에 맞게 옵션을 선택합니다.

UI Improvements

UI 편의 기능과 개선 사항, 몇 가지 버그 수정을 추가합니다.

설치 방법

  • Main Files - UI Improvements
    1. 모드 설치가 끝나면 MO2 왼쪽 패널에서 해당 모드를 더블클릭합니다.
    2. INI Files 탭에서 config\UII_Config.ini를 엽니다.
    3. 끊김 현상을 방지하기 위해 ExpandedAttributeInfo와 ExpandedSkillInfo를 0으로 설정합니다.
    4. 변경사항을 저장합니다.
