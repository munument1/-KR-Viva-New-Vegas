수동 다운로드

Root 폴더에 직접 설치하는 모드

다음 모드는 다른 모드와 달리 Mod Organizer 2를 사용하지 않고 게임의 Root 폴더에 직접 설치해야 합니다.

Manual Download를 사용하고 각 모드의 설치 지침을 따르세요.

New Vegas Script Extender (NVSE xNVSE)

원본 NVSE를 업데이트한 버전으로, 게임의 스크립트 기능을 확장합니다.

설치 방법

  • Main Files - New Vegas Script Extender (xNVSE)
    1. 다운로드한 압축 파일을 열고 모든 파일을 게임의 Root 폴더로 옮깁니다.

    Root 폴더가 무엇인지 모르겠다면 주요 용어를 확인하세요.

    파일 이름과 달리 Steam 이외 버전에서도 nvse_steam_loader.dll은 필요합니다.

    1. 정상적으로 설치했다면 Root 폴더는 다음과 비슷해야 합니다.

Vanilla BSAs Patcher

BSA 압축을 해제해 로딩을 개선하고 바닐라 음성이 재생되지 않는 문제를 수정합니다.

설치 방법

  • Main Files - Vanilla BSAs Patcher

BSA 파일을 게임 Data 폴더에서 직접 패치하거나, 패치된 복사본을 Mod Organizer 2의 모드로 불러올 수 있습니다. 백업을 끈 경우 직접 패치는 저장 공간을 약 4GB 덜 사용합니다. MO2 방식은 구성을 옮기기 쉽고, 예를 들어 Tale of Two Wastelands를 설치할 때 게임 파일 검증이나 백업 복구를 할 필요가 줄어듭니다.

Data 폴더에 직접 적용

  1. 압축을 풀고 Vanilla BSAs Patcher.exe를 실행합니다.
  2. Fallout: New Vegas 경로가 자동으로 입력되어 있어야 합니다. 비어 있다면 프로그램을 닫고 게임 런처를 다시 실행해 필요한 레지스트리 키를 생성하세요.

    3. Epic Games Store 버전은 해당 레지스트리 키를 만들지 않습니다. 게임 폴더를 직접 지정해야 합니다.

  3. 기본 설정을 권장합니다. 다만 HDD 사용자는 압축 해제를 비활성화하세요.
  4. Patch 버튼을 누릅니다.
  5. 버튼을 누르고 작업이 끝날 때까지 기다린 뒤 종료합니다.

MO2 모드로 적용

  1. MO2 상단의 모드 개수 옆 작은 렌치 아이콘을 누른 뒤 Create empty mod를 선택합니다.
  2. 모드 이름을 Patched BSAs로 지정합니다.
  3. Patched BSAs 모드를 우클릭하고 Open in Explorer를 선택합니다.
  4. 새로 열린 창의 폴더 경로를 복사합니다.
  5. 압축을 풀고 Vanilla BSAs Patcher.exe를 실행합니다.
  6. Fallout: New Vegas 경로가 자동으로 입력되어 있어야 합니다. 비어 있다면 프로그램을 닫고 게임 런처를 다시 실행해 필요한 레지스트리 키를 생성하세요.

    7. Epic Games Store 버전은 해당 레지스트리 키를 만들지 않습니다. 게임 폴더를 직접 지정해야 합니다.

  7. 기본 설정을 권장합니다. 다만 HDD 사용자는 압축 해제를 비활성화하세요.
  8. Custom output path에 앞에서 복사한 경로를 지정합니다.
  9. Patch 버튼을 누릅니다.
  10. 버튼을 누르고 작업이 끝날 때까지 기다린 뒤 종료합니다.

Ultimate Edition ESM Fixes Remastered

본편과 DLC 플러그인의 수천 개 레코드를 최적화·수정해 성능과 안정성을 높입니다.

설치 방법

  • Main Files - Ultimate Edition ESM Fixes Remastered
    1. MO2 프로필 표시줄 옆의 버튼을 누르고 Open Mods folder를 선택합니다.
    2. Mods 폴더 안에 Fixed ESMs라는 빈 폴더를 만듭니다.
    3. 해당 폴더의 경로를 복사합니다.
    4. 압축을 풀고 Installer.exe를 실행합니다.
    5. Fallout: New Vegas 경로(Root 폴더)가 자동 입력되어 있어야 합니다. 비어 있다면 프로그램을 닫고 게임 런처를 다시 실행해 필요한 레지스트리 키를 생성하세요.

      6. Epic Games Store 버전은 해당 레지스트리 키를 만들지 않습니다. 게임 폴더를 직접 지정해야 합니다.

    6. Mod folder 경로에 앞에서 복사한 경로를 지정합니다.
    7. Install을 누르고 작업이 끝날 때까지 기다린 뒤 종료합니다.
    8. Mod Organizer 2에서 F5를 눌러 왼쪽 패널을 새로고침한 뒤 Fixed ESMs를 체크해 활성화합니다.

게임 패처

게임 버전에 따라 xNVSE와 함께 사용할 패처가 다릅니다.
이 패처들은 게임이 최대 4GB RAM을 사용하게 하고 xNVSE를 자동으로 불러오게 합니다.

사용 중인 게임 버전에 맞는 패처 하나를 선택하세요.

Steam 및 GOG

4GB Patcher

Main Files - 4GB Patcher
  1. 다운로드한 압축 파일을 열고 실행 파일을 게임의 Root 폴더로 옮깁니다.
  2. FNVpatch.exe를 더블클릭해 실행합니다.
  3. 명령 프롬프트 창이 열리고 다음 문구가 표시되어야 합니다.
    FalloutNV.exe patched!
  4. 명령 프롬프트를 닫습니다. 게임 Root 폴더에 FalloutNV_backup.exe가 생성되어 있어야 합니다.

Epic Games

Epic Games Patcher

Main Files - Epic Games Patcher
  1. 다운로드한 압축 파일을 열고 모든 파일을 게임의 Root 폴더로 옮깁니다.
  2. Patcher.exe를 더블클릭해 실행합니다.
  3. 명령 프롬프트 창이 열리고 처리가 끝나면 다음 문구가 표시되어야 합니다.
    Press any key to continue...
  4. 명령 프롬프트를 닫습니다. 게임 Root 폴더에 FalloutNV_backup.exe가 생성되어 있어야 합니다.

게임 설정

Custom INI

이 단계에서는 JIP LN NVSE의 FalloutCustom.ini 기능을 이용해 기본 INI를 직접 건드리지 않고 성능과 안정성을 개선합니다.

FalloutCustom.ini는 다른 게임 INI보다 우선 적용되는 특별한 설정 파일입니다. 사용자 전용 파일이므로 게임이나 런처가 임의로 변경하지 않습니다.

설정이 덮어써질 걱정 없이 값을 바꿀 수 있고, 어떤 설정을 어느 INI에 넣어야 하는지 따로 관리할 필요도 줄어듭니다.

  1. MO2 상단의 버튼을 누르고 INI Editor를 선택합니다.
  2. FalloutCustom.ini 탭을 선택합니다. 정상이라면 비어 있어야 하며, 내용이 있다면 모두 지웁니다.

    3. FalloutCustom.ini 탭이 보이지 않는다면:

    1. MO2 상단의 버튼을 누릅니다.
    2. 모든 옵션을 활성화합니다.

  3. 다음 내용을 붙여넣습니다.

가이드에서 안내하지 않은 다른 INI 설정은 변경하지 않는 것을 강력히 권장하며, BethINI 같은 도구도 사용하지 않는 것이 좋습니다. 실제로는 이 가이드에 포함된 설정만으로 충분합니다.

유틸리티 작동 확인

  1. PC를 재부팅합니다. 재부팅하지 않으면 일부 플러그인이 로드되지 않을 수 있습니다.
  2. 앞의 모드들과 동일하게 Mod Organizer 2로 ML Utilities Checker를 설치합니다.
  3. MO2에서 New Vegas로 게임을 실행합니다. NVSE 항목을 선택하지 마세요.
  4. 메인 메뉴에 도착한 뒤 몇 초 기다리면 Utilities Checker 메시지 창이 나타납니다.

    5. 검사에 실패한 유틸리티가 있다면 먼저 FAQ를 확인하세요. 그래도 해결되지 않으면 ModdingLinked Discord에서 지원 스레드를 열 수 있습니다.

  5. 게임을 종료하고 ML Utilities Checker를 비활성화합니다.

성능 가이드

게임의 성능 문제, 화면 표시 문제, Alt+Tab 문제를 자세히 다루는 성능 가이드입니다. DXVK, 프레임 제한, 디스플레이 모드, 지연, HDR 등을 설명합니다.
