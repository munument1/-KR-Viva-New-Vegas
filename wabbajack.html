Wabbajack

Wabbajack이란?

Wabbajack은 자동 모드리스트 설치 도구입니다. Viva New Vegas Extended 전체를 비교적 간단하게 설치할 수 있으며, 개선된 LOD와 압축 해제된 플러그인 같은 추가 요소도 포함됩니다.

소개 및 초기 설정

먼저 소개를 읽고 초기 설정 페이지를 진행하세요. 완료한 뒤 이 페이지로 돌아와 계속 진행합니다.

중요:
Viva New Vegas Wabbajack은 Steam 글로벌판과 GOG판만 지원합니다.

설치

  1. 최신 Wabbajack을 다운로드합니다.
  2. Windows 기본 폴더와 게임 폴더 바깥에 새 폴더를 만듭니다.
    Example: C:\Modding\Wabbajack
  3. 다운로드한 Wabbajack.exe를 해당 폴더에 넣고 실행합니다.
  4. Browse Modlists를 누른 뒤 갤러리에서 Viva New Vegas를 찾아 모서리의 다운로드 버튼을 누릅니다.
  5. Installation Location에는 다음 위치가 아닌 빈 폴더를 지정합니다.
    • Steam 폴더,
    • Windows 기본 폴더,
    • 게임 폴더,
    • Wabbajack.exe를 넣어둔 폴더.
    Example: C:\Modding\Viva New Vegas
  6. Begin을 눌러 설치를 시작합니다.
  7. Nexus Mods API 연결 요청을 승인합니다.
  8. Nexus Premium 사용자가 아니라면 각 모드마다 다운로드 버튼을 직접 눌러야 합니다.
  9. 설치가 완료되면 초록색 Installation Complete 화면이 표시됩니다.
    • 빨간색 Installation Failed 화면이 뜨면 Wabbajack 설정에서 다시 로그인한 뒤 같은 폴더에 재설치를 시도하세요. 그래도 해결되지 않으면 ModdingLinked Discord에서 지원을 받으세요.

설치 후 작업

보안 예외 설정

MO2의 가상 파일 시스템 동작 방식 때문에 Windows가 MO2나 모드 파일 로드를 차단할 수 있어 이 작업이 필요합니다. 수동 설치에서는 MO2 설치 프로그램이 예외 처리를 담당하지만 Wabbajack 설치는 그렇지 않으므로 직접 설정합니다.
  1. Windows 보안을 엽니다.
  2. 바이러스 및 위협 방지를 엽니다.
  3. 바이러스 및 위협 방지 설정 아래의 설정 관리를 누릅니다.
  4. 아래로 내려 제외 항목의 제외 추가 또는 제거를 누릅니다.
  5. 폴더 예외를 추가하고 Wabbajack의 Installation Location 폴더를 지정합니다.

타사 백신을 사용한다면 해당 백신의 예외 설정에서 같은 폴더를 예외로 추가해야 합니다.

Root Mods 설치

  1. Wabbajack 화면에서 Open in File Explorer를 누릅니다.
  2. Files Requiring Manual Install 폴더를 엽니다.
  3. 안의 모든 파일을 게임 Root 폴더로 복사합니다.
  4. 게임 Root 폴더에서 FNVpatch.exe를 더블클릭해 실행합니다.
  5. 명령 프롬프트 창이 열리고 다음 문구가 표시되어야 합니다.
    FalloutNV.exe patched!
  6. 명령 프롬프트를 닫습니다. FalloutNV_backup.exe 파일이 생성되어 있다면 패치가 정상 적용된 것입니다.

Mod Organizer 2 설정

  1. Installation Location에서 ModOrganizer.exe를 실행합니다.
  2. FalloutNV_lang.esp was found 팝업이 뜨면 Yes를 선택합니다.
  3. Register? 팝업이 뜨면 Yes를 선택합니다.

Vanilla BSAs Patcher

BSA 압축을 해제해 로딩을 개선하고 바닐라 음성이 재생되지 않는 문제를 수정합니다.

여기의 설치 방법을 따르세요.

게임 설정

  1. MO2에서 Fallout Launcher를 선택해 게임 런처를 엽니다.
  2. 런처에서 Options를 누른 뒤 다음과 같이 설정합니다.
    1. Ultra Preset을 선택합니다.

      PC 성능이 매우 낮다면 대신 Medium Preset을 선택해도 됩니다.

    2. Resolution을 모니터의 기본 해상도로 설정합니다.

      런처 목록에 원하는 해상도가 없다면 다음 단계를 따르세요.

      1. 런처를 닫습니다.
      2. MO2 상단의 버튼을 누르고 INI Editor를 선택합니다.
      3. FalloutPrefs.ini 탭을 선택합니다.
      4. Display 항목에서 다음 값을 변경합니다.
        iSize W = 화면 가로 해상도.
        iSize H = 화면 세로 해상도.

  3. 런처를 닫습니다.

성능 가이드

게임의 성능 문제, 화면 표시 문제, Alt+Tab 문제를 자세히 다루는 가이드입니다. DXVK, 프레임 제한, 디스플레이 모드, 지연, HDR 등을 설명합니다.

게임 실행

Viva New Vegas Extended 없이 기본 구성만 플레이하려면 지금 MO2 모드 목록 상단의 드롭다운 메뉴에서 프로필을 전환하세요.

Mod Organizer 2의 동작 방식상 모드를 불러오려면 게임을 MO2를 통해 실행해야 합니다. 오른쪽 위 실행 항목에서 New Vegas를 선택하세요.

편의를 위해 Run 버튼 아래에서 바로가기를 생성하면 매번 MO2를 직접 열 필요가 없습니다.

Q: NVSE로 실행해야 하는 것 아닌가요?

A: 4GB Patcher와 Epic Games Patcher는 게임 기본 실행 파일이 스크립트 익스텐더를 자동으로 불러오도록 해줍니다.

이 단계에서 문제가 생기면 FAQ에서 추가 설명과 해결 방법을 확인하세요.

유틸리티 작동 확인

  1. 메인 메뉴에 도착한 뒤 몇 초 기다리면 Utilities Checker 메시지 창이 나타납니다.

    검사에 실패한 유틸리티가 있다면 먼저 FAQ를 확인하세요. 그래도 해결되지 않으면 ModdingLinked Discord에서 지원 스레드를 열 수 있습니다.

  2. 게임을 종료하고 왼쪽 패널의 Utilities 구분선 아래에서 ML Utilities Checker를 비활성화합니다.

이제 Viva New Vegas Wabbajack 리스트 설치가 완료되었습니다. 추가 모드를 원하지 않는다면 바로 플레이해도 됩니다. 즐겁게 플레이하세요!

한국어판 사용자: 게임을 시작하기 전에 VNV 한국어 패처를 적용하세요. Wabbajack으로 리스트를 업데이트한 뒤에도 MO2를 종료하고 최신 패처로 Output을 생성한 뒤 INSTALL.txt에 안내된 경로로 복사해 덮어쓰세요.

마무리 안내

가이드 도움 없이 직접 모드를 추가하는 것은 필요한 지식과 작업 흐름을 충분히 익힌 뒤 권장합니다. 게임의 기술적 구조부터 xEdit와 The Method를 이용한 충돌 해결까지 이해하는 것이 좋습니다.

관련 자료는 자료 페이지에서 확인할 수 있습니다. 또한 피해야 할 도구와 피해야 할 모드도 확인하세요.

가이드 외 모드를 추가한 구성, 특히 지나치게 많은 모드를 추가한 구성은 원본 ModdingLinked에서 지원받기 어려울 수 있습니다.

모드리스트 업데이트

리스트 업데이트 방법

모드리스트 새 버전이 공개되면 다음과 같이 업데이트합니다.
  1. Steam 또는 GOG Galaxy에서 게임 파일을 검증합니다.
  2. Wabbajack을 다시 실행하고 현재 리스트가 설치된 동일한 폴더를 지정합니다.
  3. Wabbajack 작업이 끝나면 4GB Patcher를 다시 실행합니다. 필요하면 BSA Decompressor도 다시 실행하세요. 두 작업의 설명은 위에 있습니다.

  1. 기존 캐릭터를 계속 사용할 경우 업데이트가 Safe Mid-Game으로 표시되어 있는지 반드시 확인하세요.
  2. 설치 후 직접 추가한 모드가 있다면 왼쪽 패널의 모드 이름 앞에 [NoDelete]를 붙이세요. 업데이트 후 위치가 바뀌거나 비활성화될 수 있습니다.
