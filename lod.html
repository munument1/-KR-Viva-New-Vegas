개요

LOD 이해하기

LOD는 Level Of Detail의 약자로, 먼 거리의 오브젝트를 단순화된 메시와 텍스처로 표시해 성능을 확보하는 시스템입니다. Bethesda 게임에서 LOD는 주로 먼 거리의 지형 셀 묶음을 표현하는 Cell LOD를 뜻합니다.

Cell LOD는 연속적인 거리 단계가 아니라 해당 셀이 로드되었는지 아닌지에 따라 전환됩니다. LOD Block 거리 설정은 LOD가 시작되는 지점이 아니라 LOD 자체의 최대 표시 거리를 조절합니다.
따라서 이 값을 바꿔도 LOD가 실제 오브젝트로 전환되는 거리는 동일하며 팝인은 같은 지점에서 발생합니다.

Cell LOD는 크게 세 종류로 나뉩니다.

  1. Object LOD - 건물, 바위 등 정적 오브젝트의 단순화된 버전입니다. 품질 단계는 하나이며 비교적 빠르게 생성됩니다.
  2. Terrain LOD - 셀 그룹의 지형을 표현하며 거리별로 LOD4(4x4), LOD8(8x8) 등 여러 단계가 있습니다. 구조가 복잡해 생성 시간이 가장 오래 걸립니다.
  3. Tree LOD - 식생을 2D 평면으로 표현합니다. 이름과 달리 실제 나무보다는 작은 식물에 적합하며, 큰 나무는 보통 Object LOD로 처리됩니다.

왜 LOD를 직접 생성하나요?

바닐라 LOD는 미리 생성된 고정 데이터라 모드가 바꾼 지형이나 오브젝트를 반영하지 못합니다. 현재 모드 구성에 맞춰 LOD를 새로 생성하면 다음과 같은 이점이 있습니다.

  • 근거리와 원거리 오브젝트의 외형 일관성 향상.
  • 더 많은 오브젝트가 원거리에서도 표시됨.
  • 설치한 텍스처 모드와 일치하는 LOD 텍스처.
  • 저해상도 바닐라 LOD보다 높은 품질.
  • 셀 전환 때 오브젝트가 갑자기 나타나던 빈 공간 완화.

Viva New Vegas는 VNV Extended까지 포함해도 Terrain LOD 재생성이 필수는 아닙니다. 다만 사용자 추가 모드 구성을 고려해 이 가이드에서는 Object LOD와 Terrain LOD를 모두 설명합니다.

Tale of Two Wastelands 사용자를 위한 추가 지침도 함께 포함되어 있습니다.

커스텀 LOD는 시각 품질을 크게 높이는 대신 약간의 성능 비용이 있습니다. 대부분의 최신 시스템에서는 충분히 감수할 만한 수준입니다.

LOD 비교

슬라이더를 움직여 생성된 LOD 적용 전후를 비교할 수 있습니다. 드롭다운에서 다른 비교 장면을 선택할 수 있습니다.

준비

MO2에 구분선 만들기

  1. MO2 왼쪽 패널의 빈 공간을 우클릭하고 Create separator를 선택합니다.
  2. 구분선 이름을 LOD로 지정합니다.

INI 조정

다음 설정은 LOD 표시 거리를 늘리고 SpeedTree 식생의 눈에 띄는 전환 현상을 줄입니다.

  1. MO2 상단의 버튼을 누르고 INI Editor를 선택합니다.
  2. Mod Organizer 2 페이지에서 설정한 내용이 들어 있는 FalloutCustom.ini 탭을 선택합니다.
  3. 파일 맨 아래에 다음 내용을 붙여넣습니다.

중요:
LOD 거리를 늘리면 Object LOD가 Vegas의 impostor 메시까지 표시되어 서로 겹치는 문제가 생길 수 있습니다.

가이드에 포함된 Goodies에는 이 문제를 해결하는 스크립트가 들어 있습니다.
독립적인 수정만 원한다면 Impostors and LOD Flicker Fix를 사용하세요.

충돌 해결

이 항목은 Tale of Two Wastelands 사용자에게는 해당되지 않습니다.

Yukichigai Unofficial Patch(YUP)에는 새로 생성한 LOD와 충돌하는 일부 LOD 에셋이 포함되어 있습니다.
다음과 같이 처리하세요.
  1. Mod Organizer 2 왼쪽 패널에서 Yukichigai Unofficial Patch를 더블클릭합니다.

    2. 설치 방식이나 설치 당시 지정한 이름에 따라 모드 이름은 조금 다를 수 있습니다.

  2. Filetree 탭으로 이동합니다.
  3. 다음 폴더를 우클릭하고 Hide를 선택해 숨깁니다.
    • meshes\landscape\lod
    • textures\landscape\lod

LOD 생성

xLODGen

xLODGen은 xEdit 기반의 LOD 생성 도구입니다. xEdit처럼 하나의 실행 파일에 인자를 추가해 대상 게임에 맞게 동작하도록 설정합니다.

경고!
Nexus의 FNVLODGen은 사용하지 마세요. 매우 오래되어 특히 Tree LOD가 깨지는 등 문제가 발생할 수 있습니다.

정상적인 결과물을 위해 xLODGen 130 이상을 사용해야 합니다.

  1. 여기에서 최신 xLODGen을 다운로드합니다.
  2. 다운로드가 끝나면 Windows 기본 폴더 바깥의 원하는 위치에 압축을 풉니다.
  3. MO2 상단의 버튼을 눌러 실행 파일 설정을 엽니다.
  4. 창 상단의 +를 누르고 Add from file...을 선택합니다.
  5. xLODGen 설치 폴더로 이동해 xLODGenx64.exe를 선택합니다.
  6. 오른쪽 패널의 Arguments에 -FNV -O:"C:\Output"를 입력합니다.

    7. 이 인자는 LOD 결과물을 Windows가 설치된 C 드라이브의 Output 폴더로 보냅니다.
    원한다면 출력 경로를 다른 위치로 바꿔도 됩니다. UAC 보호 폴더나 게임 폴더는 사용하지 마세요.

    LOD 생성 전에 출력 폴더가 비어 있는지 확인하세요.

Terrain LOD

이 단계에서는 Terrain LOD를 생성합니다. 가장 느리고 CPU 부하가 큰 단계일 수 있지만 원거리 지형의 디테일을 크게 향상합니다.

시간이 부족하거나 CPU가 느리다면 Build diffuse와 Build normal을 해제해 텍스처 생성을 건너뛸 수 있습니다. 생성 시간이 크게 줄어듭니다.

알아둘 점:

  • Object LOD 생성 시 지하에 묻힌 삼각형을 제거하는 데 Terrain LOD 데이터가 사용되므로 Terrain LOD를 먼저 생성해야 합니다.
    순서를 지키지 않으면 소스 데이터 불일치 때문에 Object LOD의 일부 삼각형이 사라질 수 있습니다.

    두 LOD를 동시에 생성하면 LODGen이 Terrain LOD부터 처리하므로 걱정하지 않아도 됩니다.
  • 지형을 추가·수정하는 모드를 설치하거나 지형 텍스처를 바꿀 때마다 Terrain LOD를 다시 생성해야 합니다.
  • 이미 LOD를 생성했고 이후 텍스처만 바꿨다면 Build meshes를 해제하고, Build diffuse와 Build normal만 체크해 텍스처만 다시 생성할 수 있습니다.

생성:
  1. MO2 오른쪽 위 실행 목록에서 xLODGen을 선택하고 Run을 누릅니다.
  2. worldspaces 목록을 우클릭하고 Select All을 선택합니다.
  3. 오른쪽 패널에서 Objects LOD와 Trees LOD 체크를 해제합니다.
  4. 오른쪽 패널에서 Terrain LOD를 체크합니다.
  5. Landscape LOD는 거리에 따라 네 단계로 나뉘며 LOD4가 가장 가깝고 LOD32가 가장 멉니다.

    모든 LOD 단계는 한 번에 생성됩니다. 각 단계의 설정만 맞추면 됩니다.
    원하는 단계 하나를 고르는 방식이 아닙니다. 이는 품질 "프리셋"이 아니라 게임이 LOD를 사용하는 구조입니다.

    아래 이미지대로 각 LOD 단계의 설정을 맞춥니다.
    • LOD 4:
    • LOD 8:
    • LOD 16:
    • LOD 32:

    설정 설명

    • Protect borders: 셀 경계에서 지형이 갑자기 내려앉는 현상을 방지합니다.
    • Size: VNV 같은 구성에서는 LOD4 512, 이후 단계 256이면 대부분 충분합니다. 고해상도 환경이나 지형 리텍스처를 사용하면 더 높은 값이 유리할 수 있지만 생성 시간과 결과물 용량이 크게 늘어날 수 있습니다.
    • Bake normal-maps: 실제 지형 노멀맵과 비슷한 질감이 나도록 Terrain LOD 텍스처를 조정합니다.
    • Mipmap: 약간의 VRAM과 저장 공간을 사용하는 대신 픽셀 크롤링 현상을 줄입니다.
    • Quality: LOD 지오메트리의 디테일을 조절합니다. 값이 낮을수록 메시 삼각형이 많아져 디테일이 높지만 약간의 성능 비용이 생깁니다.
    • Optimize Unseen: 지정 높이 아래의 지오메트리 삼각형 수를 줄여 물속처럼 보이지 않는 영역을 최적화합니다.
  6. Generate를 누릅니다.
  7. 작업이 끝나면 로그가 멈추고 마지막에 "LOD generation done"이 표시됩니다. 이제 xLODGen을 닫아도 됩니다.
설치:
  1. MO2 상단 모드 개수 옆 작은 렌치 아이콘을 누르고 Create empty mod를 선택합니다.
  2. 모드 이름을 FNVLODGen Output - Terrain으로 지정합니다.
  3. LOD 결과물이 생성된 위치로 이동해 textures와 meshes 폴더를 모두 선택합니다.
  4. 두 폴더를 방금 만든 FNVLODGen Output - Terrain 모드 폴더로 잘라내기/이동합니다. 모드를 우클릭하고 Open in Explorer를 선택하면 됩니다.
  5. MO2에서 메뉴가 열려 있지 않은 상태로 F5를 누른 뒤 새 모드의 체크박스를 켜 활성화합니다.

Object LOD

이 단계에서는 Object LOD와 Tree LOD를 생성합니다. 가장 빠르고 간단하며 가장 흔히 사용하는 방식입니다.

게임 월드의 오브젝트를 추가·수정하는 모드를 설치하거나 오브젝트 텍스처를 바꿀 때마다 Object LOD를 다시 생성해야 합니다.

생성:
  1. MO2 오른쪽 위 실행 목록에서 xLODGen을 선택하고 Run을 누릅니다.
  2. worldspaces 목록을 우클릭하고 Select All을 선택합니다.
  3. 아래 이미지와 동일하게 모든 설정을 맞춥니다.

    4. "in UV range"처럼 잠겨 있는 설정은 Fallout: New Vegas에 적용되지 않아 수정할 수 없으므로 무시하세요.

    설정 설명

    • Atlas size: atlas는 Object LOD 메시가 사용하는 텍스처를 하나로 모은 이미지입니다. 크기를 늘리면 더 많은 텍스처와 더 높은 해상도를 담을 수 있습니다.
      도구는 실제 필요한 크기로만 atlas를 만듭니다. 예를 들어 1024x512만 필요하다면 결과도 그 크기가 되며 여기서 지정하는 값은 최대 허용 크기입니다.
    • Max texture size: 이 해상도를 넘는 오브젝트 텍스처는 atlas에 들어가지 않습니다. 필요한 텍스처가 빠지지 않도록 값을 높게 설정합니다.
  4. Generate를 누릅니다.
  5. 작업이 끝나면 로그가 멈추고 마지막에 "LOD generation done"이 표시됩니다. 이제 xLODGen을 닫아도 됩니다.
설치:
  1. MO2 상단 모드 개수 옆 작은 렌치 아이콘을 누르고 Create empty mod를 선택합니다.
  2. 모드 이름을 FNVLODGen Output - Objects로 지정합니다.
  3. LOD 결과물이 생성된 위치로 이동해 textures와 meshes 폴더를 모두 선택합니다.
  4. 두 폴더를 방금 만든 FNVLODGen Output - Objects 모드 폴더로 이동합니다. 모드를 우클릭하고 Open in Explorer를 선택하면 됩니다.
  5. MO2에서 메뉴가 열려 있지 않은 상태로 F5를 누른 뒤 새 모드의 체크박스를 켜 활성화합니다.

중요:
LOD 생성을 마친 뒤에는 매번 왼쪽 패널에서 다음 모드를 비활성화하세요.

  • High Priority Core
  • High Priority Trees - Vanilla
나중에 LOD를 다시 생성할 때는 LODGen 실행 전에 이 모드들을 다시 활성화해야 합니다.
이 플러그인들은 실제 게임 플레이에는 필요 없지만 올바른 LOD 생성에 필요합니다.


다른 LOD 리소스는 비활성화하지 마세요. 게임에서 LOD가 정상 작동하는 데 필요합니다.

생성한 LOD는 모드 목록에서 항상 가장 마지막에 로드되어야 합니다.

다른 모드, 특히 NMC's Texture Pack 같은 텍스처 모드가 생성된 LOD를 덮어쓰면 인게임 LOD가 깨질 수 있습니다.

LOD를 BSA로 패킹하기

필수 단계는 아니지만 LOD 에셋을 최적화된 BSA 아카이브로 묶으면 로딩 시간이 줄어들어 새 지역에 진입할 때 끊김을 줄일 수 있습니다.

  1. BSArch Pro를 다운로드합니다.
  2. 다운로드가 끝나면 압축을 풉니다.
  3. BSArchPro.exe를 실행합니다.
  4. Mod Organizer 2에서 FNVLODGen Output - Objects를 우클릭하고 Open in Explorer를 선택합니다.
  5. 새로 열린 창에서 meshes 폴더를 BSArch Pro로 드래그합니다.
  6. 다음과 비슷한 화면이 나타나야 합니다.
  7. Pack 버튼을 누릅니다.
  8. 새 창이 열리면 ...을 누르고 FNVLODGen Output - Objects 폴더로 이동합니다.
  9. 폴더에 들어간 뒤 File name에 VNV LOD Plugins - Objects - Meshes.bsa를 입력하고 Save를 누릅니다. 정상적으로 진행했다면 다음과 비슷한 창이 표시됩니다.
  10. OK를 누릅니다.
  11. 패킹이 끝나면 다음과 비슷한 창이 표시됩니다.

    Create .override for New Vegas를 누른 뒤 OK를 누릅니다.
  12. BSArch Pro 메인 창으로 돌아가 Clear List를 누릅니다.
  13. textures 폴더에도 5~6단계를 반복합니다. 그다음 Ctrl+A로 모든 파일을 선택하고 우클릭해 Set Compressed Where Applicable을 누릅니다.

    14. Object 텍스처만 압축해야 합니다. Object 텍스처는 매우 크며(Tale of Two Wastelands에서는 2GB를 넘는 경우가 흔함) 월드스페이스 진입 시 한 번 로드되므로 압축은 초기 로딩에만 주로 영향을 줍니다.

    반대로 Object 메시와 Landscape 데이터는 이동 중 계속 스트리밍되므로 압축하면 인게임 로딩 성능이 오히려 나빠질 수 있습니다.

  14. 7~12단계를 반복하되 아카이브 이름에서 Meshes 대신 Textures를 사용합니다.
  15. FNVLODGen Output - Objects 폴더의 textures와 meshes 폴더를 삭제합니다.
  16. Terrain LOD도 생성했다면 FNVLODGen Output - Terrain을 대상으로 4~15단계를 반복하되 압축하지 마세요. 아카이브 이름도 Terrain에 맞게 변경합니다.

BSA 사용 시 주의사항

BSA를 올바르게 사용하려면 다음 사항을 기억하세요.

  • BSA는 같은 이름을 공유하는 플러그인에 의해 로드됩니다. 그래서 여기서 생성하는 BSA 이름이 "VNV LOD Plugins"로 시작합니다.
    따라서 BSA 역시 연결된 플러그인의 로드 순서를 따릅니다.
  • 같은 플러그인에 연결된 BSA는 파일 탐색기에서 이름 기준으로 정렬했을 때와 같은 영숫자 순서로 로드됩니다.
  • Archive Invalidation 때문에 loose 파일은 항상 BSA 내부 파일보다 우선합니다.

    따라서 다른 모드가 추가하는 파일을 주의해야 합니다. 특히 다음 폴더를 확인하세요.
    • meshes\landscape\lod
    • textures\landscape\lod
    필요하면 MO2에서 해당 폴더를 숨겨 로드되지 않게 할 수 있습니다.

    Mod Organizer 2 → Settings → Workarounds에서 Enable archives parsing을 켜면 어떤 모드가 BSA를 덮어쓰는지 확인할 수 있습니다.
  • 기본적으로 뒤에 로드되는 아카이브가 앞선 BSA의 파일을 덮어쓸 수 없는 경우가 있습니다.
    JIP LN의 override 기능이 이 동작을 바꾸므로 ".override" 파일이 필요합니다.
