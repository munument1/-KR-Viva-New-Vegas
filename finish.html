확장 구성 마무리

Stewie Tweaks - VNV Extended INI

VNV Extended 구성에 맞춘 편의 기능, 버그 수정, 성능 패치, 게임플레이 변경 설정 모음입니다.

설치 방법

  • Stewie Tweaks - VNV Extended INI
    • 모드를 다운로드한 뒤 MO2 상단의 버튼을 눌러 방금 받은 파일을 선택해 수동 설치합니다.
  • 이 모드를 Bug Fixes 구분선으로 옮깁니다. VNVE용 INI를 사용할 경우 기존 Stewie Tweaks - VNV INI는 제거해도 됩니다.

로드 순서 적용

마지막 단계는 설치된 플러그인의 로드 순서를 적용하는 것입니다. 가이드에는 충돌 관계를 고려해 미리 준비된 loadorder.txt가 제공됩니다.

  1. 여기에서 VNV Load Order 파일을 다운로드합니다.
  2. MO2 상단의 버튼을 누르고 Open Profile folder를 선택합니다.
  3. loadorder.txt를 MO2 프로필 폴더로 옮깁니다. 기존 파일을 덮어쓸지 묻는 창이 뜨면 Yes를 누릅니다.
  4. MO2에서 메뉴가 열려 있지 않은 상태로 F5를 누릅니다.

MO2 오른쪽 패널의 Plugins 탭에 표시되는 로드 순서는 방금 받은 loadorder.txt와 일치해야 합니다. 설치하지 않은 모드의 플러그인은 없어도 되지만, 남아 있는 플러그인의 순서는 파일과 같아야 합니다.

순서가 다르다면 상단 Priority 열 제목을 눌러 우선순위 기준으로 정렬했는지 확인하세요.

필요하다면 ModdingLinked Discord에서 지원을 받을 수 있습니다.

게임 실행

Mod Organizer 2의 동작 방식상 모드를 불러오려면 게임을 MO2를 통해 실행해야 합니다. 오른쪽 위 실행 항목에서 New Vegas를 선택하세요.

편의를 위해 Run 버튼 아래에서 바로가기를 생성하면 매번 MO2를 직접 열 필요가 없습니다.


Q: NVSE로 실행해야 하는 것 아닌가요?

A: 4GB Patcher와 Epic Games Patcher는 게임 기본 실행 파일이 스크립트 익스텐더를 자동으로 불러오도록 해줍니다.

이 단계에서 문제가 생기면 FAQ에서 추가 설명과 해결 방법을 확인하세요.
