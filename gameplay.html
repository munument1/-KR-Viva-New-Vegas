Agua Fria - JSawyer Redone

원본 JSawyer 리밸런스를 재구성한 모드입니다. 다양한 설정 가능한 변경 사항 중 핵심은 다음과 같습니다.
  • 초기 체력과 소지 중량 감소.
  • 레벨업 속도 감소.
  • 최대 레벨 감소.
  • 하드코어 모드 밸런스 조정.

설치 방법

  • Main Files - Agua Fria
  • Main Files - Agua Fria INI

JAM - Just Assorted Mods

빠른 루팅 메뉴, 동적 조준점, 달리기 등 현대적인 기능을 다수 추가합니다. 게임 내 일시정지 메뉴의 Mod Configuration Menu에서 세부 설정을 조정할 수 있습니다.

설치 방법

  • Main Files - Just Assorted Mods
  • Viva New Vegas Resources
    • Main Files - JAM - VNV Configuration
  • JLM Grab Tweak
    • Main Files - JLM Grab Tweak
  • Clean Just Assorted Mods (JAM)
    • Main Files - Clean Just Assorted Mods

Viva New Vegas용 JAM 프리셋은 다음 기능만 사용합니다.

  • Dynamic Crosshair - 무기 탄퍼짐에 따라 크기가 변하는 현대식 조준점.
  • Hit Marker - 적중 여부를 조준점에 표시.
  • Hit Indicator - 피해가 들어오는 방향을 화살표로 표시.
  • Loot Menu - 컨테이너를 바라보면 열리는 Fallout 4 방식의 빠른 루팅 메뉴.
  • Weapon Wheel - 빠르게 사용할 수 있는 원형 메뉴.
  • 달리기 기능은 Enhanced Movement가 대신하므로 기본적으로 비활성화되어 있습니다.

Enhanced Movement

이동 관련 버그 수정, 1인칭 대각선 이동, 개선된 달리기·은신·기울이기, 포복 애니메이션 프레임워크, 신규 애니메이션 등을 제공하는 이동 확장 모드입니다.

설치 방법

  • Main Files - Enhanced Movement
  • Main Files - Enhanced Movement INI
    1. 모드 설치가 끝나면 MO2 왼쪽 패널에서 해당 모드를 더블클릭합니다.
    2. INI Files 탭에서 config/EnhancedMovement.ini를 엽니다.
    3. 아래는 VNV 권장 설정이지만 취향에 따라 다르게 조정해도 됩니다.
      • iSprintSpeedBonus를 30으로 설정합니다.
      • fAgilitySpeedBonus를 0.25로 설정합니다.
      • iCost_AP를 10으로 설정합니다.
    4. 변경사항을 저장합니다.
