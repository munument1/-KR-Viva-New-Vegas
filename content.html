Creating a Separator in MO2

  1. Right-click the empty space in the left pane of MO2 and select Create separator.
  2. Name the separator Content.

Better Brotherhood

Goodies

Large collection of restored content, consistency fixes, integrated content, and "gray area" bug fixes.

Installation instructions

  • Main Files - Goodies
    • Download the mod, then install it manually by pressing the button at the top of MO2 and selecting the file you just downloaded.
    • You will be prompted with a FOMOD installer:
      1. Better Brotherhood (only if you installed Better Brotherhood)
      2. Install
  • Goodies INI
    1. Download the mod, then install it manually by pressing the button at the top of MO2 and selecting the file you just downloaded.
    2. Once the mod has been installed, double-click it in the left pane of MO2.
    3. In the INI Files tab, open config\Goodies.ini
    4. Set bOnFireLines and bOnFireAnim to 0.
    5. Save your changes.
  • Viva New Vegas Resources
    • Main Files - Goodies - Jacobstown Water Fix

The fire lines and animations were cut for sounding too realistic and graphic. Keep them enabled if you don't mind.
