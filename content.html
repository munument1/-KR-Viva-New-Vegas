콘텐츠

MO2에 구분선 만들기

  1. MO2 왼쪽 패널의 빈 공간을 우클릭하고 Create separator를 선택합니다.
  2. 구분선 이름을 Content로 지정합니다.

The Living Desert

수백 명의 새로운 NPC와 스크립트 이벤트를 추가해 세계가 더 살아 있고 플레이어의 행동에 반응하는 느낌을 줍니다.

설치 방법

  • Main Files - The Living Desert Main File
  • Main Files - The Living Desert .ini

Better Brotherhood

모하비 브라더후드를 더 완성도 높은 세력으로 만드는 조정 모드입니다. 평판 획득 경로 추가, 엔딩 슬라이드 조건 수정, 추가 수리 서비스, 레벨드 리스트 개선, 신규 무기 등을 포함합니다.

설치 방법

  • Main Files - Better Brotherhood

Goodies

복원 콘텐츠, 일관성 수정, 통합 콘텐츠, 그리고 명확한 버그 여부가 애매한 부분까지 손보는 대규모 모음입니다.

설치 방법

  • Main Files - Goodies
    • 모드를 다운로드한 뒤 MO2 상단의 버튼을 눌러 방금 받은 파일을 선택해 수동 설치합니다.
    • FOMOD 설치 화면이 나타납니다.
      1. Better Brotherhood를 설치한 경우에만 Better Brotherhood 옵션을 선택합니다.
      2. Install
  • Goodies INI
    1. 모드를 다운로드한 뒤 MO2 상단의 버튼을 눌러 방금 받은 파일을 선택해 수동 설치합니다.
    2. 모드 설치가 끝나면 MO2 왼쪽 패널에서 해당 모드를 더블클릭합니다.
    3. INI Files 탭에서 config\Goodies.ini를 엽니다.
    4. bOnFireLines와 bOnFireAnim을 0으로 설정합니다.
    5. 변경사항을 저장합니다.
  • Viva New Vegas Resources
    • Main Files - Goodies - Jacobstown Water Fix
