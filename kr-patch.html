Viva New Vegas 한국어 패치

Viva New Vegas 설치를 마친 뒤 한국어 패쳐로 번역 파일을 생성해 적용합니다. 비공식 한국어 패치이며, ModdingLinked의 공식 배포물이 아닙니다.

패쳐 다운로드

VNV Korean Patcher v1.0.7.3 다운로드

별도로 Python을 설치할 필요는 없습니다.

설치 방법

  1. Viva New Vegas 설치를 완료한 뒤 tNVSE Font Plugin 71을 MO2에 설치하고 활성화합니다.
  2. MO2에 Viva New Vegas Extended 프로필이 있는지 확인하고 MO2를 종료합니다.
  3. 다운로드한 패쳐를 실행하고 ModOrganizer.ini가 있는 MO2 인스턴스 폴더를 선택합니다.
  4. Output 생성을 누릅니다.
  5. 기존 파일을 백업한 후 Output/mods 안의 모드 폴더를 MO2의 실제 mods 폴더에 복사해 병합합니다.
  6. MO2에서 생성된 한국어 모드를 활성화하고, 오른쪽 플러그인 목록의 VNVKR UI Strings.esp도 활성화합니다. VNV Korean Fonts - tNVSE는 왼쪽 목록에서 원본 tNVSE보다 아래에 배치합니다.

복사 전 확인: Output/INSTALL.txt에 적힌 실제 설치 경로를 확인하세요. Output/overwrite가 생성되었다면 안내된 Overwrite 경로에도 해당 파일을 복사해야 합니다.

패쳐는 번역 파일을 Output에 생성할 뿐, MO2에 자동 설치하거나 프로필·로드 순서를 변경하지 않습니다. 번역된 플러그인을 모두 일괄 활성화하지 마세요.

업데이트 및 자세한 안내

모드팩을 업데이트했다면 패쳐를 다시 실행해 새 Output을 생성하세요. 이전 Output을 그대로 재사용하지 마세요.

v1.0.7.2 이하 패쳐를 사용한 경우, 기존에 덮어쓴 ESP/ESM은 원본 파일 또는 적용 전 백업으로 복구한 뒤 새 버전을 적용해야 합니다.

기술 설명, 변경 이력 및 자세한 주의사항은 패쳐 GitHub README와 릴리즈 노트를 참고하세요.
