Viva New Vegas 한국어 패치

비공식 한국어 프로젝트
이 패처는 ModdingLinked의 공식 배포물이 아닙니다. Viva New Vegas는 영문판 게임을 기준으로 설치한 뒤, 별도의 한국어 패처로 Output을 생성하고 사용자가 MO2 경로에 복사하는 방식입니다. 패처는 실제 MO2나 게임 파일을 직접 변경하지 않습니다.

최신 버전 · v1.0.7.3

플러그인 전체 재저장을 중단하고 원본 바이너리의 승인된 문자열과 필요한 길이 정보만 변경합니다. 프로필은 읽기만 하며 프로필 파일은 출력하거나 변경하지 않습니다. 번역 파일만 Output에 생성합니다.

tNVSE 수정 DLL과 기존 SST/MCM/라디오/UI 번역을 유지합니다. 단일 EXE이며 별도 Python 설치는 필요하지 않습니다.

  • VNVKoreanPatcher-v1.0.7.3.exe 다운로드
  • v1.0.7.3 릴리즈 노트 보기
  • SHA-256: 6629765f8da4e16b89db708d069ed9a1b25fff06c43a34cc4d9b2ec4b0afba3b

1.0.7.2 이하 버전의 Output은 다시 생성하세요. 이미 ESP/ESM을 덮어썼다면 해당 파일을 원래 영문 모드 파일이나 적용 전 백업으로 복구한 뒤 새 패쳐를 실행하세요. 새 버전은 이미 변경된 비번역 데이터를 자동 복구하지 않습니다. 사용자 설정·프로필·세이브는 삭제하지 마세요.

필수 · 원본 tNVSE 71 먼저 설치

한국어 출력에는 tNVSE Font Plugin 71이 필요합니다. tNVSE는 한글을 포함한 멀티바이트 문자열 렌더링과 입력을 지원하지만, 번역 자체를 제공하는 모드는 아니므로 반드시 아래 한국어 패처와 함께 사용해야 합니다.

  1. tNVSE Font Plugin에서 71 버전을 다운로드합니다.
  2. 파일을 Mod Organizer 2로 일반 모드처럼 설치합니다.
  3. MO2 왼쪽 모드 목록에서 tNVSE가 활성화되어 있는지 확인합니다.
  4. VNV 가이드를 정상적으로 완료했다면 tNVSE가 요구하는 xNVSE, JIP LN NVSE, Stewie Tweaks, Shader Loader 계열 요구사항은 이미 설치되어 있어야 합니다.
  5. tNVSE 설치가 끝난 뒤 아래의 VNV Korean Patcher를 실행합니다.

중요: 원본 tNVSE는 기존처럼 먼저 설치해야 합니다. 패처는 기존 VNV Korean Fonts - tNVSE 폴더에 수정 NVSE/plugins/tnvse.dll과 한국어 설정·폰트를 Output에 생성합니다. Output을 복사한 뒤 MO2에서 KR Font 모드를 직접 활성화하고 원본 tNVSE보다 높은 우선순위에 두세요. 원본 tNVSE의 셰이더와 UI 파일은 기존 설치를 사용합니다.

언제 적용하나요?

Viva New Vegas 수동 설치 또는 Wabbajack 설치를 모두 마친 뒤 적용하는 것을 권장합니다. 패처는 Viva New Vegas Extended 프로필과 설치된 플러그인을 확인하므로, VNV 업데이트 후에도 다시 실행해 새 Output을 생성해 복사할 수 있습니다.

설치 방법

  1. 원본 tNVSE 71과 선행 모드를 기존 가이드대로 설치·활성화합니다.
  2. MO2에 Viva New Vegas Extended 프로필이 있는지 확인하고 MO2를 종료합니다.
  3. VNVKoreanPatcher-v1.0.7.3.exe를 실행하고 ModOrganizer.ini가 있는 VNV 인스턴스 폴더를 선택합니다.
  4. Output 생성을 누릅니다. 이 단계에서는 MO2나 게임 파일을 변경하지 않습니다.
  5. 덮어쓸 기존 모드 파일을 백업합니다.
  6. Output/mods 안의 모드 폴더를 실제 MO2 Mods 폴더에 복사해 병합합니다.
  7. MO2를 열고 VNV Korean Fonts - tNVSE, VNV Korean UI Strings, VNV Korean Radio Captions와 생성된 경우 VNV Korean Translations의 활성화 상태를 확인합니다. 한국어 폰트 모드는 원본 tNVSE보다 높은 우선순위에 둡니다.
  8. 오른쪽 플러그인 목록에서 VNVKR UI Strings.esp도 활성화합니다. 다른 모드·플러그인의 활성화 상태와 순서는 유지하며 전체 ESP를 일괄 활성화하지 않습니다.
  9. Output/INSTALL.txt에서 실제 Mods/Overwrite 경로와 수동 활성화 항목을 확인하세요. 프로필 파일은 복사하지 않습니다.

Output의 mods 폴더 안에 있는 모드 폴더를 실제 Mods 경로로 병합합니다. 기존 MO2 Overwrite 제공 파일의 번역본이 출력된 경우에는 INSTALL.txt에 안내된 해당 경로로 파일을 복사합니다. 출력에 없는 기존 파일을 삭제하지 마세요.

modlist.txt·plugins.txt·loadorder.txt는 생성하거나 변경하지 않습니다. 이전 버전 Output의 profiles 폴더도 복사하지 마세요.

VNV 업데이트 대응 방식

  • 기존 지원 플러그인: 현재 MO2/VFS의 winner ESP/ESM에 전용 xTranslator SST를 우선 적용합니다.
  • SST가 없는 플러그인: FalloutNV.esm 및 공식 DLC SST에서 원 소유자, FormID, 레코드 타입, 필드 경로, 현재 영문 원문이 모두 같은 항목만 자동 상속합니다.
  • 공식 미니 DLC: ClassicPack, MercenaryPack, TribalPack, CaravanPack은 stock VNV처럼 게임 Data에서 읽되, 번역본은 Output/mods의 Fixed ESMs 폴더에 생성합니다.
  • 게임 Data의 플러그인: 별도 MO2 provider가 없으면 원본을 읽어 Output/mods/VNV Korean Translations에 번역본을 생성합니다. 기존 모드가 제공하는 파일은 해당 모드의 Output 경로에 생성합니다.
  • MCM: JSON에 직접 들어 있는 표시 문자열은 JSON에서 병합하고, $키 방식은 해당 MCM/Translation INI를 번역합니다.
  • 원문이 변경된 항목: 추측해서 덮어쓰지 않고 영어를 유지하며 미대응 항목으로 보고합니다.

패치 결과 확인

작업이 끝나면 Output.report.txt와 Output.report.json에 번역 결과와 복사할 프로필 파일 정보를 기록합니다. Output 생성 완료는 실제 설치 완료를 의미하지 않습니다. 정상 패치, 이미 적용됨, 업데이트 전체/일부 적용, 업데이트 미적용, 제거됨, 신규 플러그인 번역 상속 성공/미대응을 구분해 확인할 수 있습니다.

복사 전 백업과 업데이트

Output을 덮어쓰기 전에 덮어쓸 기존 모드 파일을 사용자가 백업하세요. 패처는 실제 설치 파일이나 프로필을 변경하지 않으므로 자동 설치 백업을 만들지 않습니다.

모드팩 업데이트나 모드 변경 후에는 이전 Output을 재사용하지 말고 새로 생성하세요. 프로필은 읽기만 하며 활성화 상태와 로드 순서는 자동으로 바꾸지 않습니다.

패처를 업데이트할 때

새 패처 버전은 별도 폴더에 다운로드해 실행하는 것을 권장합니다. VNV 자체가 업데이트된 경우에도 MO2를 종료하고 새 패처로 Output을 생성한 뒤 안내된 경로에 복사하면 됩니다. 이전 Output은 덮어쓰지 않습니다.
