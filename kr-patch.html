Viva New Vegas 한국어 패치

비공식 한국어 프로젝트
이 패처는 ModdingLinked의 공식 배포물이 아닙니다. Viva New Vegas는 영문판 게임을 기준으로 설치한 뒤, 별도의 한국어 패처로 번역 파일을 생성하는 방식입니다. 원본 VNV 파일은 패처가 직접 수정하지 않습니다.

최신 버전 · v1.0.3

VNV 업데이트에 따라 플러그인이 변경되거나 새 플러그인이 추가되어도 가능한 범위에서 기존 본편/DLC 번역을 안전하게 재사용하도록 개선된 버전입니다.

  • VNVKoreanPatcher-v1.0.3.zip 다운로드
  • v1.0.3 릴리즈 노트 보기
  • SHA-256: AFE8180D1D52A11A487349F70876DA9F57F7A6B27E9DA1A8EE049F4304C3CBF7

언제 적용하나요?

Viva New Vegas 수동 설치 또는 Wabbajack 설치를 모두 마친 뒤 적용하는 것을 권장합니다. 패처는 현재 MO2 프로필과 설치된 플러그인을 확인하므로, VNV 업데이트 후에도 다시 실행해 새 Output을 만들 수 있습니다.

설치 방법

  1. 위의 최신 ZIP을 다운로드하고 원하는 폴더에 압축을 풉니다.
  2. VNVKoreanPatcher.exe를 실행합니다.
  3. ModOrganizer.ini가 있는 Viva New Vegas MO2 폴더를 선택합니다. 일반적인 Wabbajack 설치 예시는 C:\Modlists\VNV입니다.
  4. Output 생성을 누릅니다. 패처는 원본 파일을 직접 수정하지 않고 별도의 Output을 만듭니다.
  5. 생성된 Output\mods 폴더를 선택한 VNV MO2 폴더로 복사해 기존 mods 폴더와 병합합니다.
  6. 패처 창에 표시되는 안내에 따라 새 한국어 모드와 필요한 ESP를 MO2에서 활성화합니다.
  7. 문제가 있거나 일부 번역이 적용되지 않았다면 패치 결과 보기를 눌러 상세 보고서를 확인합니다.

VNV 업데이트 대응 방식

  • 기존 지원 플러그인: 검증된 버전은 빠른 xdelta 경로를 사용하고, 버전이 달라지면 레코드 단위로 안전하게 기존 번역을 다시 적용합니다.
  • 삭제된 플러그인: 현재 VNV에 파일이 없으면 오류로 중단하지 않고 생성 대상에서 제외한 뒤 보고서에 기록합니다.
  • 새 플러그인: FalloutNV.esm 및 공식 DLC ESM의 검증된 번역 데이터와 비교합니다. 원 소유자, FormID, 레코드 타입, 필드 경로와 현재 영문 원문이 일치하는 항목만 자동 번역합니다.
  • 원문이 변경된 레코드: 잘못된 번역을 덮어쓰지 않도록 영어를 유지하고 미대응 항목으로 보고합니다.
  • 이미 한국어가 적용된 파일: 검증된 결과 해시와 일치하면 느린 재병합 없이 그대로 재사용합니다.

패치 결과 확인

작업이 끝나면 Output.report.txt와 Output.report.json이 생성됩니다. 정상 패치, 이미 적용됨, 업데이트 전체/일부 적용, 업데이트 미적용, 제거됨, 신규 플러그인 번역 상속 성공/미대응을 구분해 확인할 수 있습니다.

패처를 업데이트할 때

새 패처 버전이 나오면 기존 프로그램 폴더에 덮어쓰기보다 새 버전을 별도 폴더에 풀어 실행하는 것을 권장합니다. VNV 자체가 업데이트된 경우에도 새 패처로 Output을 다시 생성한 뒤 MO2의 한국어 모드 파일을 교체하면 됩니다.
