Viva New Vegas 한국어 패치

비공식 한국어 프로젝트
이 패처는 ModdingLinked의 공식 배포물이 아닙니다. Viva New Vegas는 영문판 게임을 기준으로 설치한 뒤, 별도의 한국어 패처로 번역본을 MO2에 설치하는 방식입니다. 교체 전 파일과 프로필을 백업하며 게임 Data 원본은 유지합니다.

최신 버전 · v1.0.7

v1.0.7은 GMST·단축키 문자열 치환의 인코딩을 수정한 tNVSE DLL을 포함하고, 번역 파일을 실제 MO2 모드 경로에 설치하며 선택한 프로필의 필요한 한국어 모드·플러그인을 자동 활성화합니다. 라디오/UI 및 터미널 번역 텍스처의 누락된 설치 목록도 복구했습니다.

약 54MB의 단일 EXE이며 별도 Python 설치가 필요하지 않습니다. 기존 SST/XEditLib 번역 및 저장본 검증 방식을 유지합니다.

  • VNVKoreanPatcher-v1.0.7.exe 다운로드
  • v1.0.7 릴리즈 노트 보기
  • SHA-256: DD9E8166A2639F4C60710E847F9C2BEF7C6854DD280E05484EA4B6F4388293EB

Windows/Linux 회귀 테스트 49개와 tNVSE 문자열 변환 테스트, EXE 패키지 검증을 통과했습니다. 실제 게임에서의 GMST·단축키 표시 및 MO2 적용 확인은 아직 진행하지 않았습니다.

필수 · 원본 tNVSE 71 먼저 설치

한국어 출력에는 tNVSE Font Plugin 71이 필요합니다. tNVSE는 한글을 포함한 멀티바이트 문자열 렌더링과 입력을 지원하지만, 번역 자체를 제공하는 모드는 아니므로 반드시 아래 한국어 패처와 함께 사용해야 합니다.

  1. tNVSE Font Plugin에서 71 버전을 다운로드합니다.
  2. 파일을 Mod Organizer 2로 일반 모드처럼 설치합니다.
  3. MO2 왼쪽 모드 목록에서 tNVSE가 활성화되어 있는지 확인합니다.
  4. VNV 가이드를 정상적으로 완료했다면 tNVSE가 요구하는 xNVSE, JIP LN NVSE, Stewie Tweaks, Shader Loader 계열 요구사항은 이미 설치되어 있어야 합니다.
  5. tNVSE 설치가 끝난 뒤 아래의 VNV Korean Patcher를 실행합니다.

중요: 원본 tNVSE는 기존처럼 먼저 설치해야 합니다. 패처는 기존 VNV Korean Fonts - tNVSE 폴더에 수정 NVSE/plugins/tnvse.dll과 한국어 설정·폰트를 설치합니다. 해당 KR Font 모드를 자동 활성화하고 높은 우선순위에 배치해 DLL을 덮어씁니다. 원본 tNVSE의 셰이더와 UI 파일은 기존 설치를 사용합니다.

언제 적용하나요?

Viva New Vegas 수동 설치 또는 Wabbajack 설치를 모두 마친 뒤 적용하는 것을 권장합니다. 패처는 Viva New Vegas Extended 프로필과 설치된 플러그인을 확인하므로, VNV 업데이트 후에도 다시 실행해 다시 번역을 설치할 수 있습니다.

설치 방법

  1. 위의 원본 tNVSE 71과 선행 모드 설치·활성화를 완료합니다.
  2. MO2에서 한국어 패치를 적용할 프로필을 선택한 뒤 MO2를 종료합니다.
  3. VNVKoreanPatcher-v1.0.7.exe를 다운로드해 실행합니다.
  4. ModOrganizer.ini가 있는 VNV MO2 인스턴스 폴더를 선택합니다. 일반적인 Wabbajack 설치 예시는 C:\Modlists\VNV입니다.
  5. 한국어 패치 설치를 누릅니다. 패처가 번역본을 검증하고 실제 Mods/Overwrite 경로에 설치합니다. Mods나 Profiles가 외부 드라이브에 있어도 설정된 경로를 사용합니다.
  6. 완료 메시지에서 적용한 프로필과 백업 경로를 확인합니다. Output 수동 복사나 한국어 모드·플러그인의 추가 체크는 필요하지 않습니다.
  7. MO2를 다시 열고 해당 프로필로 게임을 실행합니다. 일부 번역이 적용되지 않았다면 패치 결과 보기에서 상세 보고서를 확인합니다.

기존에 꺼둔 선택 모드는 유지하며 다른 프로필의 텍스트 파일은 수정하지 않습니다.

VNV 업데이트 대응 방식

  • 기존 지원 플러그인: 현재 MO2/VFS의 winner ESP/ESM에 전용 xTranslator SST를 우선 적용합니다.
  • SST가 없는 플러그인: FalloutNV.esm 및 공식 DLC SST에서 원 소유자, FormID, 레코드 타입, 필드 경로, 현재 영문 원문이 모두 같은 항목만 자동 상속합니다.
  • 공식 미니 DLC: ClassicPack, MercenaryPack, TribalPack, CaravanPack은 stock VNV처럼 게임 Data에서 읽되, 번역본은 게임 폴더가 아니라 MO2의 Fixed ESMs에 설치합니다.
  • 게임 Data의 플러그인: 별도 MO2 provider가 없으면 원본을 읽어 VNV Korean Translations 모드에 번역본을 설치합니다. Overwrite의 플러그인은 백업 후 이 모드로 옮겨 원본이 번역본을 가리지 않게 합니다.
  • MCM: JSON에 직접 들어 있는 표시 문자열은 JSON에서 병합하고, $키 방식은 해당 MCM/Translation INI를 번역합니다.
  • 원문이 변경된 항목: 추측해서 덮어쓰지 않고 영어를 유지하며 미대응 항목으로 보고합니다.

패치 결과 확인

작업이 끝나면 Output.report.txt와 Output.report.json에 번역 결과, 설치 상태와 백업 경로를 기록합니다. 정상 패치, 이미 적용됨, 업데이트 전체/일부 적용, 업데이트 미적용, 제거됨, 신규 플러그인 번역 상속 성공/미대응을 구분해 확인할 수 있습니다.

백업과 복구

교체 전 모드 파일과 선택한 프로필은 패처 옆 Output.backup 폴더에 저장합니다. 재실행 시에는 새 Output 이름에 .backup이 붙습니다. 설치 중 오류가 발생하면 변경한 파일을 되돌립니다.

복구할 때는 MO2를 종료하고 패처가 있는 폴더에서 아래 명령을 실행합니다. 따옴표 안을 실제 백업 폴더 경로로 바꾸세요.

VNVKoreanPatcher-v1.0.7.exe --restore "C:\패처 폴더\Output.backup"

설치 이후 파일을 별도로 변경했다면 덮어쓰지 않도록 복구가 중단됩니다. 백업 폴더는 확인이 끝날 때까지 보관하세요.

패처를 업데이트할 때

새 패처 버전은 별도 폴더에 다운로드해 실행하는 것을 권장합니다. VNV 자체가 업데이트된 경우에도 MO2를 종료하고 새 패처로 한국어 패치를 다시 설치하면 됩니다. 이전 Output과 백업은 덮어쓰지 않습니다.
