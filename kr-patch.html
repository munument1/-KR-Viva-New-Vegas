Viva New Vegas 한국어 패치

비공식 한국어 프로젝트
이 패처는 ModdingLinked의 공식 배포물이 아닙니다. Viva New Vegas는 영문판 게임을 기준으로 설치한 뒤, 별도의 한국어 패처로 번역 파일을 생성하는 방식입니다. 원본 VNV 파일은 패처가 직접 수정하지 않습니다.

최신 버전 · v1.0.6

v1.0.6은 플러그인 번역 원본을 xTranslator SST로 통일하고, 전용 SST가 없는 플러그인은 FalloutNV/공식 DLC SST의 동일 레코드·필드·영문 원문만 안전하게 상속합니다. MCM JSON의 직접 표시 문자열과 MCM/Translations/*.ini, config/*_Translations.ini 번역도 함께 생성합니다.

Node.js·Koffi·YesMan 런타임과 전체 CP1252 반복 검증을 제거했습니다. 플러그인은 Python + XEditLib로 UTF-8 적용 후 저장본을 한 번 다시 열어 구조와 번역 결과를 검증합니다. 배포물은 약 48MB의 단일 EXE입니다.

필수 · tNVSE 71 이상 설치

한국어 출력에는 tNVSE Font Plugin 71 이상이 필요합니다. tNVSE는 한글을 포함한 멀티바이트 문자열 렌더링과 입력을 지원하지만, 번역 자체를 제공하는 모드는 아니므로 반드시 아래 한국어 패처와 함께 사용해야 합니다.

  1. tNVSE Font Plugin에서 최신 버전 71 이상을 다운로드합니다.
  2. 파일을 Mod Organizer 2로 일반 모드처럼 설치합니다.
  3. MO2 왼쪽 모드 목록에서 tNVSE가 활성화되어 있는지 확인합니다.
  4. VNV 가이드를 정상적으로 완료했다면 tNVSE가 요구하는 xNVSE, JIP LN NVSE, Stewie Tweaks, Shader Loader 계열 요구사항은 이미 설치되어 있어야 합니다.
  5. tNVSE 설치가 끝난 뒤 아래의 VNV Korean Patcher를 실행합니다.

중요: 한국어 패처에는 tNVSE 본체 DLL이 포함되어 있지 않습니다. 패처가 생성하는 tnvse.ini, tnvse_fonts.xml, 한국어 폰트 및 관련 설정은 이미 설치된 tNVSE 위에 적용되는 구성입니다.

언제 적용하나요?

Viva New Vegas 수동 설치 또는 Wabbajack 설치를 모두 마친 뒤 적용하는 것을 권장합니다. 패처는 현재 MO2 프로필과 설치된 플러그인을 확인하므로, VNV 업데이트 후에도 다시 실행해 새 Output을 만들 수 있습니다.

설치 방법

  1. 먼저 위의 tNVSE 71 이상 설치와 활성화를 완료합니다.
  2. 위의 최신 VNVKoreanPatcher-v1.0.6.exe를 다운로드합니다.
  3. VNVKoreanPatcher.exe를 실행합니다.
  4. ModOrganizer.ini가 있는 Viva New Vegas MO2 폴더를 선택합니다. 일반적인 Wabbajack 설치 예시는 C:\Modlists\VNV입니다.
  5. Output 생성을 누릅니다. 패처는 원본 파일을 직접 수정하지 않고 별도의 Output을 만듭니다.
  6. 생성된 Output\mods 폴더를 선택한 VNV MO2 폴더로 복사해 기존 mods 폴더와 병합합니다.
  7. 패처 창에 표시되는 안내에 따라 새 한국어 모드와 필요한 ESP를 MO2에서 활성화합니다.
  8. 문제가 있거나 일부 번역이 적용되지 않았다면 패치 결과 보기를 눌러 상세 보고서를 확인합니다.

VNV 업데이트 대응 방식

  • 기존 지원 플러그인: 현재 MO2/VFS의 winner ESP/ESM에 전용 xTranslator SST를 우선 적용합니다.
  • SST가 없는 플러그인: FalloutNV.esm 및 공식 DLC SST에서 원 소유자, FormID, 레코드 타입, 필드 경로, 현재 영문 원문이 모두 같은 항목만 자동 상속합니다.
  • 공식 미니 DLC: ClassicPack, MercenaryPack, TribalPack, CaravanPack은 stock VNV처럼 게임 Data에서 읽되, 번역본은 게임 폴더가 아니라 Output의 Fixed ESMs에 생성합니다.
  • MCM: JSON에 직접 들어 있는 표시 문자열은 JSON에서 병합하고, $키 방식은 해당 MCM/Translation INI를 번역합니다.
  • 원문이 변경된 항목: 추측해서 덮어쓰지 않고 영어를 유지하며 미대응 항목으로 보고합니다.

패치 결과 확인

작업이 끝나면 Output.report.txt와 Output.report.json이 생성됩니다. 정상 패치, 이미 적용됨, 업데이트 전체/일부 적용, 업데이트 미적용, 제거됨, 신규 플러그인 번역 상속 성공/미대응을 구분해 확인할 수 있습니다.

패처를 업데이트할 때

새 패처 버전이 나오면 기존 프로그램 폴더에 덮어쓰기보다 새 버전을 별도 폴더에 풀어 실행하는 것을 권장합니다. VNV 자체가 업데이트된 경우에도 새 패처로 Output을 다시 생성한 뒤 MO2의 한국어 모드 파일을 교체하면 됩니다.

전체 릴리즈 목록은 GitHub Releases에서 확인할 수 있습니다.
