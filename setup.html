준비

VC++ 재배포 패키지 설치

대부분의 엔진 모드와 도구는 최신 Visual C++ 재배포 패키지가 필요합니다. Windows 공식 패키지 관리자인 Winget을 사용하면 필요한 패키지를 빠르고 안전하게 최신 상태로 맞출 수 있습니다. 먼저 Microsoft Store를 통해 Winget 자체를 최신 버전으로 업데이트해 스크립트가 정상 작동하도록 합니다.

최신 버전이 설치되어 있지 않으면 게임이나 모딩 도구를 실행하자마자 종료될 수 있습니다.

이미 설치되어 있더라도 오래된 버전일 가능성이 있으므로 재배포 패키지를 다시 설치해 주세요.

  1. Microsoft Store를 엽니다.
  2. 업데이트 및 다운로드 항목으로 이동합니다.
  3. 업데이트 확인을 누르고 모든 항목의 업데이트를 완료합니다.
  4. 완료되면 명령 프롬프트를 관리자 권한으로 열고 다음 명령을 입력합니다.
  5. PC를 재부팅합니다.

파일 확장자 표시 켜기

작업을 시작하기 전에 Windows에서 파일 확장자가 보이도록 설정해야 합니다.

기본 설정에서는 파일 탐색기가 .exe, .dll, .esp 같은 확장자를 숨깁니다. 이 가이드에서는 확장자를 구분해야 하는 경우가 많으므로 반드시 표시하는 것을 권장합니다.

  1. 파일 탐색기를 엽니다.
  2. 상단의 보기 메뉴를 선택합니다.
  3. 표시 항목에서 파일 확장명을 켭니다.

기본 주소 강제 랜덤화 비활성화

기본 주소 랜덤화는 프로그램의 시작 주소를 무작위로 배치하는 Windows 보안 기능입니다. Fallout: New Vegas 같은 32비트 프로그램에서는 예상되지 않은 동작을 만들 수 있으며, 모드 환경에서 충돌의 원인이 될 수 있습니다.

기본적으로 꺼져 있어야 하지만 실제로 비활성화되어 있는지 확인하는 것을 권장합니다.

  1. 시작 메뉴에서 Windows 보안을 엽니다.
  2. 왼쪽 메뉴에서 앱 및 브라우저 컨트롤을 선택합니다.
  3. Exploit Protection 아래의 Exploit Protection 설정을 엽니다.
  4. 이미지에 대한 강제 임의 지정(Mandatory ASLR)이 기본값 사용(끔)으로 설정되어 있는지 확인합니다.

    5. 시스템 전체 설정을 바꾸고 싶지 않다면 Fallout: New Vegas만 예외로 추가할 수 있습니다.

    1. 프로그램 설정을 선택합니다.
    2. 사용자 지정할 프로그램 추가를 선택합니다.
    3. 프로그램 이름으로 추가를 선택합니다.
    4. 입력란에 FalloutNV.exe를 입력하고 저장합니다.
    5. 목록에서 새로 만든 항목을 찾아 편집을 누릅니다.
    6. 이미지에 대한 강제 임의 지정(Mandatory ASLR)을 찾습니다.
    7. 시스템 설정 재정의를 체크하고 스위치를 끔으로 설정합니다.

설치

설치 위치 선택

깨끗한 재설치는 이전 모드 파일의 잔재를 없애기 위해서뿐 아니라 게임을 안전한 위치에 설치하기 위해서도 필요합니다. 설치 위치를 고를 때 다음 사항을 확인하세요.

  • Windows 기본 폴더를 피하세요: C:\Program Files, C:\Program Files x86, 바탕 화면, 문서 등이 포함됩니다.
    Program Files는 쓰기 권한 제한이 있고, 바탕 화면과 문서 폴더는 OneDrive가 관리하는 경우가 많아 게임과 모딩 도구에서 여러 문제를 일으킬 수 있습니다.

    안전한 위치의 예: C:\Games
  • 가능하면 SSD에 설치하세요: 로딩 시간이 크게 줄고 끊김 현상도 감소합니다.

기존 게임 제거

이전에 게임을 설치한 적이 없다면 다음 항목으로 바로 넘어가세요.

Steam, GOG, Epic Games 버전별로 제거 방법이 다릅니다. 본인이 사용하는 버전에 해당하는 설명만 따르면 됩니다.

Steam

이미 게임을 제거했다면 잔여 파일을 없애기 위해 4번과 5번 단계는 반드시 확인하세요.

  1. Steam을 열고 라이브러리로 이동합니다.
  2. 목록에서 Fallout: New Vegas를 찾습니다.
  3. 우클릭한 뒤 관리 → 제거를 선택합니다.
  4. Steam\steamapps\common으로 이동해 Fallout New Vegas 폴더가 남아 있다면 삭제합니다.
  5. Documents\My Games\FalloutNV로 이동해 내부의 INI 파일을 모두 삭제합니다.

GOG

  1. GOG를 열고 라이브러리로 이동합니다.
  2. 목록에서 Fallout: New Vegas를 찾습니다.
  3. 우클릭한 뒤 Manage Installation → Uninstall을 선택합니다.
    • 오프라인 설치 프로그램을 사용했다면 게임 Root 폴더의 unins000.exe를 실행합니다.
  4. Documents\My Games\FalloutNV로 이동해 내부의 INI 파일을 모두 삭제합니다.

Epic Games

이미 게임을 제거했다면 잔여 파일을 없애기 위해 4번 단계는 반드시 확인하세요.

  1. Epic Games Launcher를 열고 라이브러리로 이동합니다.
  2. 목록에서 Fallout: New Vegas를 찾습니다.
  3. 점 3개 메뉴를 누른 뒤 제거를 선택합니다.
  4. Documents\My Games\FalloutNV_Epic으로 이동해 내부의 INI 파일을 모두 삭제합니다.

게임 설치

앞서 설명했듯 본인이 사용하는 스토어 버전에 해당하는 지침만 따르면 됩니다.

Steam

새 Steam 라이브러리 만들기

게임은 Program Files (x86) 같은 Windows 기본 폴더 밖에 설치하는 것을 강력히 권장합니다. 해당 폴더의 엄격한 파일 보호 기능 때문에 일부 모드나 도구가 정상 작동하지 않을 수 있습니다. 여기서는 Steam Library Setup Tool을 사용해 안전한 위치에 새 Steam 라이브러리를 만듭니다.

Steam 자체가 이미 Windows 기본 폴더 밖에 설치되어 있고 별도 라이브러리를 사용 중이라면 다음 항목의 1번 단계로 넘어가 해당 라이브러리에 게임을 설치하세요.

  1. 작업 관리자나 시스템 트레이를 이용해 Steam을 완전히 종료합니다.
  2. 여기에서 steam_library_setup_tool-3.2.exe를 다운로드합니다.
  3. 다운로드한 파일을 실행하고 Add Row를 눌러 새 항목을 추가합니다.
  4. Path에 원하는 경로를 입력합니다. 예: C:\Games\Steam
  5. Accept를 누르고 새 폴더 생성 여부를 물으면 Yes를 선택합니다.
  6. 도구가 종료 여부를 물으면 OK를 누릅니다.
  1. Steam을 열고 라이브러리로 이동합니다.
  2. 목록에서 Fallout: New Vegas를 찾아 설치를 선택합니다.
  3. 설치 위치:에서 방금 만든 라이브러리 폴더를 선택합니다. 기본 C 드라이브에 만들었다면 두 번째 C:\ 항목으로 표시될 수 있습니다.
  4. 다음을 누르고 설치가 끝날 때까지 기다립니다.

새 라이브러리가 보이지 않는다면 PC를 재부팅하세요.

GOG

  1. GOG를 열고 라이브러리로 이동합니다.
  2. 목록에서 Fallout: New Vegas를 찾아 설치를 선택합니다.
  3. Install to 위치를 원하는 경로로 지정합니다.
    • 게임은 반드시 Program Files x86 같은 Windows 기본 폴더 밖에 설치해야 합니다.

Epic Games

  1. Epic Games Launcher를 열고 라이브러리로 이동합니다.
  2. 목록에서 Fallout: New Vegas를 찾습니다.
  3. 게임을 클릭해 설치를 시작합니다.
    • 게임은 반드시 Program Files x86 같은 Windows 기본 폴더 밖에 설치해야 합니다.

설치 후 작업

주요 용어

게임 설치가 끝났습니다. 이후 가이드에서 자주 언급되는 두 폴더를 알아두세요.

  • Root 폴더: 게임이 설치된 최상위 폴더입니다.
    • Steam:

      Steam\steamapps\common\Fallout New Vegas

    • GOG:

      GOG Galaxy\Games\Fallout New Vegas

      (설치 경로를 직접 바꾸지 않은 경우).
    • Epic Games:

      Epic Games\FalloutNewVegas\Fallout New Vegas English

      (설치 경로를 직접 바꾸지 않은 경우).
  • Data 폴더: 게임의 각종 데이터와 에셋이 들어 있는 폴더입니다.
    • Steam:

      Steam\steamapps\common\Fallout New Vegas\Data

    • GOG:

      GOG Galaxy\Games\Fallout New Vegas\Data

    • Epic Games:

      Epic Games\FalloutNewVegas\Fallout New Vegas English\Data

새 INI 파일 생성

  1. Steam/GOG Galaxy에서 게임을 실행합니다. 오프라인판이라면 게임 폴더의 FalloutNVLauncher.exe를 실행합니다.
  2. Detecting Video Hardware라고 표시되는 두 팝업에서 모두 OK를 누릅니다.
    • 팝업이 뜨지 않는다면 Documents\My Games\FalloutNV의 INI 파일을 모두 삭제한 뒤 다시 실행합니다.
  3. OK를 누른 뒤 Exit으로 종료합니다.
