DiaMoveNVSE Patched

플레이어의 대각선 이동을 활성화합니다.

설치 방법

  • Main Files - DiaMoveNVSE Patched
    1. 모드 설치가 끝나면 MO2 왼쪽 패널에서 해당 모드를 더블클릭합니다.
    2. INI Files 탭에서 NVSE/Plugins/DiaMoveNVSE.ini를 엽니다.
    3. bEnableHeadTurn을 false로 설정합니다.
    4. fVanityModeXMult와 fVanityModeYMult를 각각 30, 10으로 설정합니다.
    5. 변경사항을 저장합니다.

설치 방법

  • Main Files - Smooth True Ironsights

Anniversary Anim Pack

무기 애니메이션을 개선하는 간단한 리애니메이션 팩입니다.

설치 방법

  • Main Files - Anniversary Anim Pack

Anniversary Anim Pack 설치 후 새 애니메이션에 맞춰 패치하려면 Iron Sights Aligned를 다시 설치해야 합니다. 다음 단계를 따르세요.

  1. Bug Fixes 구분선 아래의 Iron Sights Aligned를 우클릭하고 Reinstall Mod를 선택합니다.
    • 다운로드 폴더를 비웠다면 모드를 다시 다운로드해야 합니다.
  2. FOMOD 설치 화면이 나타납니다.
    1. Anniversary Anim Pack
    2. Yukichigai's Unofficial Patch
    3. Install
  3. 선택 창이 뜨면 Replace를 누릅니다.
  4. Iron Sights Aligned를 Anniversary Anim Pack 아래로 이동합니다.
    • MO2에서 모드를 이동할 수 없다면 왼쪽 패널이 Priority 열 기준으로 정렬되어 있는지 확인하세요.
