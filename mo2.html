Mod Organizer 2

Mod Organizer 2란?

Mod Organizer 2(MO2)는 Bethesda 게임에서 주로 사용하는 오픈 소스 모드 관리자입니다. 주요 특징은 다음과 같습니다.

  • 가상 파일 시스템(USVFS): MO2는 모드를 게임 폴더에 직접 설치하지 않고, 게임이 읽을 수 있는 가상 파일 시스템을 만듭니다. 이를 통해 다음과 같은 장점이 생깁니다.
    • 안전한 모드 설치 및 제거,
    • 언제든지 모드 설치 순서를 변경할 수 있음,
    • 서로 다른 모드 구성을 가진 여러 프로필 사용,
    • 원본 게임 파일을 깨끗하게 유지.
    USVFS의 단점은 다음과 같습니다.
    • MO2로 설치한 모드는 MO2를 통해 실행한 프로그램에서만 "보임",
    • 일부 프로그램은 MO2의 가상 파일 시스템과 정상적으로 동작하지 않을 수 있음,
    • BSA/BA2로 묶이지 않은 loose 파일이 매우 많으면 USVFS의 성능 오버헤드가 발생할 수 있음,
    • USVFS는 NVSE 플러그인이나 ReShade처럼 게임 프로세스에 "후킹"하는 방식으로 작동합니다. 메모리에 개입하는 특성 때문에 일부 백신이 위험 요소로 오탐할 수 있습니다.
  • 프로필 시스템: 서로 다른 모드 구성, 세이브, 설정을 가진 여러 프로필을 만들 수 있습니다.
  • 양쪽 패널 인터페이스: 왼쪽은 모드 목록, 오른쪽은 플러그인 목록으로 나뉘어 있어 충돌 확인과 모드 관리가 쉽습니다.
  • 이동성: USVFS 덕분에 MO2는 "포터블" 모드를 지원하며, 최소한의 재설정만으로 MO2 폴더 전체를 다른 위치로 옮길 수 있습니다.
  • 모딩 커뮤니티 연동: Nexus Mods를 기본 지원하므로 Nexus에서 모드를 MO2로 직접 다운로드할 수 있습니다.
    또한 자체 플러그인 시스템을 통해 기능을 확장할 수 있습니다.

    Mod Organizer 2는 Nexus의 Collections 기능을 지원하지 않으므로 모드를 하나씩 내려받아야 합니다.
    이 가이드가 필요한 모드의 직접 링크를 제공하므로 큰 문제는 아닙니다. 또한 Collections는 품질 관리가 충분하지 않은 경우가 많습니다.

    Collections와 가장 비슷한 대안은 Wabbajack입니다. 커뮤니티에서 만든 모드 리스트 설치기로 전체 모드 리스트를 자동으로 설치할 수 있으며, 제작자에게 요구되는 진입 장벽이 더 높아 Collections보다 품질 관리가 잘 되는 편입니다.

    공식 Viva New Vegas Wabbajack 리스트 설치 방법은 여기에서 확인할 수 있습니다.

왜 Mod Organizer 2를 사용하나요?

이 가이드에서 Mod Organizer 2를 사용하는 이유는 사용하기 쉽고, 게임 폴더를 깨끗하게 유지할 수 있기 때문입니다. 충돌 해결과 모드 관리가 쉬우며, 설치 순서를 잘못 잡아도 원하는 위치로 드래그해 바로 수정할 수 있습니다.

Vortex와 비교하면 MO2는 모딩의 핵심 구조를 사용자에게 숨기지 않기 때문에 처음에는 복잡해 보일 수 있지만, 무엇이 왜 일어나는지 이해하기가 더 쉽습니다.

물론 MO2도 완벽한 도구는 아니며 자체적인 문제와 한계가 있습니다. 그래도 이 작업에는 가장 적합한 도구입니다.

설치

Mod Organizer 2 설치

  1. 여기에서 Mod Organizer 2를 다운로드합니다.
  2. 다운로드가 끝나면 설치 프로그램을 실행합니다.
  3. 라이선스에 동의하고 Next를 누릅니다.
  4. 설치 위치를 묻는 화면에서 MO2를 Viva New Vegas로 바꾸고 Next를 누릅니다.

    다른 위치에 설치하려면 Browse 버튼을 눌러 원하는 폴더를 선택하면 됩니다.

    설치 폴더는 Program Files x86 같은 Windows 기본 폴더와 게임의 Root 폴더 밖에 있어야 합니다.

    OneDrive 같은 클라우드 동기화를 사용한다면 바탕 화면이나 문서 폴더에 MO2를 두지 않는 것을 권장합니다. 문제나 성능 저하가 생길 수 있습니다.

  5. 설치 구성 요소 화면에서는 기본값을 그대로 사용합니다.
  6. 시작 메뉴 폴더 이름을 묻는 화면에서 Mod Organizer를 Viva New Vegas로 바꾸고 Next를 누릅니다.
  7. 바탕 화면 바로가기는 만들지 마세요. 나중에 별도로 만들 예정입니다.
  8. 마지막 화면에서 Install을 누릅니다.
  9. 설치가 끝나면 Launch Mod Organizer가 체크되어 있는지 확인하고 Finish를 누릅니다.

MO2가 실행되지 않는다면 FAQ의 문제 해결 단계를 확인하세요.

설정

Mod Organizer 2 구성

  1. 인스턴스 생성 화면에서 Create a portable instance를 선택하고 Next를 누릅니다.
  2. New Vegas를 선택하고 Next를 누릅니다.
  3. 게임을 구매한 스토어를 선택하고 Next를 누릅니다.
  4. 프로필 설정 화면에서는 모든 옵션을 활성화하고 Next를 누릅니다.
  5. 파일 경로는 기본 위치를 그대로 사용합니다.
  6. 다음 화면에서 Connect to Nexus를 누릅니다.
    1. 브라우저가 열리면 연결을 승인합니다.
    2. 승인이 끝나면 브라우저를 닫고 MO2에서 Next를 누릅니다.

MO2가 여유 공간이 적은 SSD/HDD에 설치되어 있다면 Show advanced options를 체크하고 Downloads 경로를 여유 공간이 많은 다른 드라이브로 바꿀 수 있습니다.
다운로드 경로는 게임 성능에 영향을 주지 않으며, 모드 설치가 끝난 뒤 다운로드 파일을 삭제해도 됩니다.

  1. 마지막 화면에서 Finish를 선택합니다.
  2. Show tutorial? 팝업이 뜨면 No를 선택합니다.
  3. Register? 팝업이 뜨면 Yes를 선택합니다.
  4. INI file is read-only 팝업이 뜨면 아래 드롭다운에서 Remember my choice를 고른 뒤 Clear the read-only flag를 누릅니다.
  5. FalloutNV_lang.esp was found 팝업이 뜨면 Yes를 선택합니다.

게임 설정

  1. MO2에서 Fallout Launcher를 선택해 게임 런처를 엽니다.
  2. 런처에서 Options를 누른 뒤 다음과 같이 설정합니다.
    1. Ultra Preset을 선택합니다.

      PC 성능이 매우 낮다면 대신 Medium Preset을 선택해도 됩니다.

    2. Resolution을 모니터의 기본 해상도로 설정합니다.

      런처 목록에 원하는 해상도가 없다면 다음 단계를 따르세요.

      1. 런처를 닫습니다.
      2. MO2 상단의 버튼을 누르고 INI Editor를 선택합니다.
      3. FalloutPrefs.ini 탭을 선택합니다.
      4. Display 항목에서 다음 값을 변경합니다.
        iSize W = 화면 가로 해상도.
        iSize H = 화면 세로 해상도.

  3. 런처를 닫습니다.

모드 설치 방법

Nexus와 MO2 사용 방법

가이드에서 모드 설치 파일은 Main File - Example 1.5처럼 표시됩니다. 앞부분은 Nexus의 파일 분류, 뒷부분은 실제 파일 이름을 뜻합니다.

중요:
별도 지시가 없다면 항상 Mod Manager Download를 사용하세요.



모드 매니저를 이용한 기본 설치 절차:
  1. 지정된 파일을 다운로드합니다.
  2. MO2 오른쪽 실행 파일 선택 영역 아래의 Downloads 탭을 엽니다.
  3. 모드를 더블클릭해 설치합니다.
  4. 왼쪽 패널에서 모드의 체크박스를 켜 활성화합니다.

모드 매니저로 다운로드할 수 없는 경우에는 다음과 같이 합니다.
  1. Manual Download 버튼 또는 해당 사이트의 수동 다운로드 버튼을 누릅니다.
  2. 다운로드가 끝나면 MO2 상단의 버튼을 누릅니다.
  3. 새 창에서 다운로드한 파일 위치로 이동해 파일을 더블클릭합니다.
  4. Mod Manager Download로 받은 모드와 동일하게 설치를 마칩니다.

모드를 설치할 때 MO2가 다음 선택지를 표시할 수 있습니다.
  • Rename: 기존 모드와 같은 이름의 파일을 설치하려 할 때 표시됩니다. 예를 들어 모드 작동에 필요한 추가 파일을 별도로 설치하는 경우 드롭다운이나 직접 입력으로 구분 가능한 이름을 붙이세요.
  • Replace: 기존 모드를 새 버전으로 업데이트할 때 사용합니다. 이전 버전 파일을 삭제하고 새 버전으로 교체합니다.
  • Merge: 업데이트될 가능성이 없고 별도 핫픽스를 기존 모드에 합쳐야 하는 경우에만 사용하세요. 관리 편의성을 위해 가능하면 피하는 것이 좋습니다.
