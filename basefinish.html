기본 구성 마무리

로드 순서 적용

마지막 단계는 설치된 플러그인의 로드 순서를 적용하는 것입니다. 가이드에는 미리 준비된 loadorder.txt가 포함되어 있으며, 충돌 관계를 고려해 모드가 올바른 순서로 불러와지도록 구성되어 있습니다.

  1. 여기에서 VNV Load Order 파일을 다운로드합니다.
  2. MO2 상단의 버튼을 누르고 Open Profile folder를 선택합니다.
  3. loadorder.txt를 MO2 프로필 폴더로 옮깁니다. 기존 파일을 덮어쓸지 묻는 창이 뜨면 Yes를 누릅니다.
  4. MO2에서 메뉴가 열려 있지 않은 상태로 F5를 누릅니다.

MO2 오른쪽 패널의 Plugins 탭에 표시되는 로드 순서는 방금 받은 loadorder.txt와 일치해야 합니다. 설치하지 않은 모드의 플러그인은 없어도 되지만, 남아 있는 플러그인의 순서는 파일과 같아야 합니다.

순서가 다르다면 상단의 Priority 열 제목을 눌러 우선순위 기준으로 정렬했는지 확인하세요.

필요하다면 ModdingLinked Discord에서 지원을 받을 수 있습니다.

게임 실행

Mod Organizer 2의 동작 방식상 모드를 불러오려면 게임을 MO2를 통해 실행해야 합니다. 오른쪽 위 실행 항목에서 New Vegas를 선택하세요.

편의를 위해 Run 버튼 아래에서 바로가기를 생성하면 매번 MO2를 직접 열지 않고도 게임을 실행할 수 있습니다.


Q: NVSE로 실행해야 하는 것 아닌가요?

A: 4GB Patcher와 Epic Games Patcher는 게임의 기본 실행 파일이 스크립트 익스텐더를 자동으로 불러오도록 해줍니다.

이 단계에서 문제가 생기면 FAQ에서 추가 설명과 해결 방법을 확인하세요.


이제 Viva New Vegas의 기본 구성이 완료되었습니다. 추가 모드를 원하지 않는다면 이제 바로 플레이해도 됩니다. 즐겁게 플레이하세요!

한국어로 플레이하려면: 여기서 기본 구성만 사용할 경우 VNV 한국어 패처를 적용하세요. VNV Extended까지 설치할 예정이라면 Extended Finish까지 완료한 뒤 패처를 실행하는 것을 권장합니다.

VNV Extended

바닐라를 넘어 확장하기

다음 페이지부터는 Viva New Vegas Extended 구간입니다. 이 구간은 게임 플레이에 필수는 아닙니다. 다음과 같은 내용을 포함합니다.

  • UI와 편의 기능 개선.
  • 보다 현대적인 게임에 가까운 게임플레이 기능과 개선 사항.
  • 신규 및 복원 콘텐츠와 DLC 개선.
  • 밸런스 및 게임 시스템 개편.
  • NPC 외형 개선, 새로운 애니메이션, 그래픽 수정, 조명과 날씨 개편.

VNV Extended는 완전히 모듈식입니다. 특정 모드를 건너뛰어도 되지만, 그 모드에 의존하는 다른 모드나 패치도 함께 제외해야 합니다.
